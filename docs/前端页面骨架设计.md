## 零、整体架构

这是一个**单页应用（SPA）**——没有 URL 路由，4 个模式就是 4 个"页面"，通过 Zustand `activeMode` 字段做条件渲染切换。

### 顶层结构

```
┌─ AppShell ──────────────────────────────────────────────────┐
│  GlobalNavBar (桌面: 顶部 48px / 平板手机: 底部 44-48px)      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  <main> (flex-1, overflow-hidden)                           │
│    根据 activeMode 条件渲染 4 个模式组件之一                  │
│    切换时旧组件卸载、新组件挂载（Worker 不中断）               │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  GlobalNavBar (仅平板/手机在此渲染)                           │
└─────────────────────────────────────────────────────────────┘
```

### 页面总数

- **4 个模式页面**：探索模式、分析模式、实验模式、故事模式
- **1 个加载页**：Pyodide/WASM 运行时下载（首次访问必经）
- **若干全局覆盖层/弹窗**：Toast 通知、Error Boundary 降级、遮罩层、对话框

### 导航栏

桌面端在页面顶部水平排列 4 个 shadcn/ui `Tabs`（`variant="pills"`），每个带 lucide-react 图标 + 中文标签：

| 模式 | 图标 | 标签 | 快捷键 | 指示条颜色 |
|------|------|------|--------|-----------|
| 探索模式 | `Compass` | 探索模式 | `1` | `blue-500` |
| 分析模式 | `BarChart3` | 分析模式 | `2` | `emerald-500` |
| 实验模式 | `FlaskConical` | 实验模式 | `3` | `amber-500` |
| 故事模式 | `Play` | 故事模式 | `4` | `violet-500`（非激活时脉冲动画） |

平板/手机端导航栏移至页面底部，平板显示短标签+图标，手机仅显示图标+短标签（`justify-around` 均分 + `safe-area-inset-bottom`）。

## 一、加载页（SYS-04）— 首次访问必经

进入应用的第一眼不是 3D 场景，而是**全屏加载界面**：

```

│     12.3 MB / 18.0 MB                    │
│     预计剩余 15 秒                        │
│                                          │
│         [ 离线模式 ] [ 重试 ]             │
```

**元素清单**：
- 作品名 + 英文副标题（居中，`font-serif`）

#### 左侧控制面板（280px，SIM-02）

- **8+ 参数**垂直排列，每个参数一行：
  - 标签（含 LaTeX 符号如 `m₁`）+ **滑块**（`Slider`）+ **数值输入框**（`Input`）
  - 参数列表：`m₁`, `m₂`, `L₁`, `L₂`, `θ₁`, `θ̇₁`, `θ₂`, `θ̇₂`, `g`, 阻尼
  - 非法输入：输入框**红框 + 震动动画**（`animate-shake` 0.3s），上方 `Tooltip` 显示合理范围
- **视角预设**：3 个 `Button` 切换（实验员侧视 / 上帝俯视 / 混沌跟随），当前选中态高亮
- **材质切换**：`Select` 下拉（金属 / 木质 / 玻璃）——仅视觉，不影响物理
- **环境切换**：`Toggle` 或 `Select`（暗室聚光 / 纯白教学）
- **尾迹持久度**：`Select` 下拉（50 步 / 200 步 / 1000 步 / 无限 / 仅当前周期）
- **声效开关**：`Switch` 组件，默认关闭

#### 中部 3D 场景（flex-1，EXP-01）

- R3F `<Canvas>` 全高度 WebGL 渲染
- 暗室模式：`#0a0a0f` 背景 + 上方聚光灯（`SpotLight` intensity 8）+ 微弱地面网格（`#1a1a2e`）
- 纯白模式：`#f5f5f5` 背景 + 均匀环境光（`ambientLight` intensity 1.0）+ 清晰坐标系网格（`#cccccc`）
- **Canvas 内元素**：固定支点球 → 下摆杆 → 上摆球 → 上摆杆 → 下摆球 → 运动尾迹
- 摆球大小：`0.08 × m^(1/3)`（clamp 0.04-0.2）
- 摆杆粗细：`baseRadius × (1 + m × 0.15)`

**Canvas 上方覆盖层（DOM 层，z-10~20）**：

- **视角预设按钮组**（左上角）：3 个半透明 `Button`，切换时相机平滑过渡 1 秒
- **时间反演按钮**（右上角，显著位置）：带沙漏图标 `⏳`，`Button variant="secondary"`
- **蝴蝶效应分屏开关**（右上角，时间反演旁边）：`🦋` 图标
- **蝴蝶效应分离警报**（屏幕中央，条件显示）：当 |Δθ| > 90° 时出现脉冲提示"完全失相关"（`animate-pulse` + 红色半透明 Badge）

**底部工具栏**（Canvas 下方，h-10）：

```
[▶ 播放]  [⏸ 暂停]  [↺ 重置]  [⏳ 时间反演]  [🦋 蝴蝶效应]
```

#### 右侧图表面板（300px）

**上：能量实时监控面板**（SIM-04）——`Card` 容器，h-1/2

- 标题行："能量监控" + 右上角 `Badge`（漂移百分比，绿色 <0.5% / 黄色 0.5-1% / 红色 >1%）
- Canvas 2D 折线图（D3.js `d3-shape` + Canvas 绑定）：
  - 动能（`E_k`）：实线，暖色
  - 势能（`E_p`）：虚线，冷色
  - 总能量（`E_t`）：粗实线，白色/黑色（随主题）
- X 轴：时间（s），自动滚动
- Y 轴：能量（J），自适应范围
- `Tooltip`：悬浮显示精确数值

**下：相空间可视化面板**（SIM-05）——`Card` 容器，h-1/2

- 标题行 + Tab 切换（`θ₁-θ̇₁` / `θ₂-θ̇₂`）
- Canvas 2D 相平面轨迹图：
  - 实时轨迹（实线，当前色）
  - 历史轨迹（虚线半透明，可开关）
  - X 轴：θ（rad），Y 轴：θ̇（rad/s）

### 蝴蝶效应分屏状态（EXP-04 激活时）

3D 场景区域**左右均分为两个独立 Viewport**（`flex-row w-full h-full`）：

```
┌──────────────────────┬──────────────────────┐
│   摆 A (金色)         │   摆 B (紫色)         │
│                      │                      │
│   ┌── 3D Viewport ┐  │   ┌── 3D Viewport ┐  │
│   │   R3F Canvas   │  │   │   R3F Canvas   │  │
│   │   金色球/杆/尾迹 │  │   │   紫色球/杆/尾迹 │  │
│   └───────────────┘  │   └───────────────┘  │
├──────────────────────┴──────────────────────┤
│ δ = 0.000001°     |Δθ| = 127.3°            │
│ [仅调 A]  [仅调 B]  [同步调节]               │
└─────────────────────────────────────────────┘
```

- 两个 R3F `<Canvas>` 各自独立渲染，但共享同一个 Worker 的第二个实例（Worker B）
- 底部**差异溯源面板**（h-8）：实时显示初始差异 δ（精确到 10⁻⁶°）与当前角度分离度 |Δθ|
- 参数调节模式切换按钮（仅调 A / 仅调 B / 同步调节）
- 两摆的播放/暂停/重置完全同步

### 时间反演状态（EXP-05 激活时）

- 3D 场景内叠加两套轨迹：
  - **实线**（白色）：时间反演后的实际轨迹
  - **虚线**（半透明灰色，`stroke-dasharray`）：理论上应重合的原轨迹（从尾迹历史调取）
- 右侧出现**"数值漂移距离"曲线**小浮动面板（绝对定位，右上），实时展示两线分离程度
- 分离发生时自动弹出**教学注释气泡**（暗色半透明背景，居中偏上，`animate-fade-in`）：

  > "哈密顿系统理论上可逆，但混沌使计算机的浮点误差被指数放大——这就是初值敏感性的计算物理体现"

- 两种反演模式切换：`Select` 下拉（精确反演"历史插值" / 数值反演"重新积分"）
- 子面板：漂移距离随时间变化的小曲线图

### 左侧分析控制面板（260px）

- **参数轴选择**：X 轴参数下拉（如 L₂/L₁ 比 / m₂/m₁ 比）、Y 轴参数下拉（如 θ₁ 初始角）
- **图层切换**：`RadioGroup` 或 `Tabs` 切换（最大 Lyapunov / 最小 Lyapunov / 能量曲面曲率）
- **固定参数显示**：只读显示扫描时的固定参数值（m₁, m₂, g, damping）
- **色阶图例**：垂直色条（深蓝→青绿→橙红），标注 λ 值范围
- **当前仿真参数指示**：显示 SIM-02 当前的参数值，在热力图上以十字游标标记

### 图表区 Tab 切换（shadcn/ui Tabs，水平排列）

4 个 Tab 标签：`[热力图] [分岔图] [庞加莱截面] [能量景观]`

#### ANL-01 Lyapunov 热力图

- Canvas 2D 渲染 100×100 格点色块（D3.js `d3-scale-chromatic` 发散色阶）
- 鼠标悬停：`Tooltip` 显示精确 λ 值 + 对应参数坐标
- 点击格点：自动将该组参数填充至 SIM-02 → `setMode("explore")` 切换回探索模式（双向联动）
- 十字游标：标识当前仿真参数在热力图上的位置，3D 中调节参数时游标实时移动
- 数据来源：SYS-03 预计算 JSON → fetch → IndexedDB 缓存

#### ANL-02 参数空间分岔图

- Canvas 2D 散点图：横轴为扫描参数，纵轴为 θ₂ 局部极大值集合
- 周期区：离散点/线，混沌区：连续带
- 竖直游标（可拖拽）：位置对应当前仿真参数
- d3-zoom 框选放大：观察周期倍增通向混沌的细节
- 数据来源：同上 SYS-03 预计算管线

#### ANL-03 庞加莱截面

- Canvas 2D 散点图：横轴 θ₂，纵轴 θ̇₂
- **动态生长**：点随时间逐步添加（Web Worker 实时检测截面穿越），可观察"离散点 → 闭合曲线 → 奇怪吸引子"的演化
- 当前轨线（实心圆点，暖色）与历史基准轨线（空心圆，冷色）叠加对比
- 截面条件编辑器：可修改截面条件（如改为 θ₂=π/2），`Input` + `Button` 组合
- 截面长期无穿越时：Canvas 内显示空状态提示"当前参数下轨迹可能不穿过所选截面，建议更换截面条件"

#### ANL-04 能量景观地形图（P2 选做）

- 3D 半透明曲面：R3F `<Canvas>` 独立渲染（与探索模式 3D 场景无关）
- 高度映射势能 V(θ₁, θ₂)，颜色映射势能梯度
- 实时光点：当前 (θ₁, θ₂) 在曲面上投射发光小球，随运动滑动
- 等高线投影：曲面底部投射势能等高线（半透明线条）
- 相机可旋转（`OrbitControls`）观察势阱与势垒

## 五、故事模式（Story）— 沉浸式自动演示

故事模式是**全屏沉浸**体验，覆盖在所有 UI 之上。

```
┌──────────────────────────────────────────────────────────┐
│                                                    [↺重播]│
│                                                          │
│                                                          │
│              3D 场景 / 分析图表                            │
│          (自动切换模式、调节参数、旋转视角)                  │
│                                                          │
│       ┌─ 脉冲高亮光晕 ─┐  (当前可交互控件)                  │
│       │  声效开关      │                                   │
│       └──────────────┘                                   │
│                                                          │
│  ┌──────────────────────────────────────────────────┐    │
│  │  一个摆，我们知道它会在哪里                        │    │
│  └──────────────────────────────────────────────────┘    │
│           ↑ 电影式字幕 (framer-motion 淡入淡出)            │
│                                                          │
│  ──●──────────────●─────────────●─────────────●──── 时间轴│
│   intro   upgrade  butterfly  sonification  analysis     │
│                                                          │
└──────────────────────────────────────────────────────────┘
         ↑ 全屏透明点击拦截层 (z-40，任意位置点击=打断)
```

### 7 阶段时间轴（总时长 3 分 30 秒）

| 阶段 | 时间 | 画面 | 字幕 |
|------|------|------|------|
| `intro` | 0:00-0:25 | 暗色背景 + 单摆稳定摆动（m₂→0） + 实验员侧视 | "一个摆，我们知道它会在哪里" |
| `upgrade` | 0:25-0:50 | 恢复双摆 + 混沌视角跟随 + 长尾迹 | "再加一个摆，世界变得不可预测" |
| `butterfly` | 0:50-1:30 | 蝴蝶效应分屏启动 + 上帝视角俯视两摆 | "初始差异仅 0.001°，30 秒后它们形同陌路" |
| `sonification` | 1:30-2:00 | 声效开启 + 混沌视角 + 声效按钮脉冲高亮 | "混沌不仅能看见，还能听见" |
| `analysis` | 2:00-2:30 | 切换到分析模式 + 热力图高亮 → 分岔图高亮 | "这不是随机，是有结构的复杂" |
| `timereversal` | 2:30-3:00 | 回探索模式 + 时间反演启动 + 实验员侧视 | "甚至计算机也无法让混沌回头" |
| `climax` | 3:00-3:30 | 上帝视角 + 无限尾迹 + 白色教学背景 | "确定性系统的内在随机性——这就是混沌" |
| `finished` | 3:30 | 字幕消失 → `storyEnd` 事件 → 自动退出回之前模式 | — |

### 故事模式 UI 元素

- **字幕条**（底部居中，z-50）：
  - `framer-motion` `AnimatePresence` 淡入淡出（duration 0.6s）
  - 暗色半透明背景（`bg-black/70 backdrop-blur-sm`）+ 白色衬线字体（`font-serif text-xl`）
  - `pointer-events-none`（不拦截点击，点击穿透到打断层）
  - `max-w-2xl`，最多 2 行

- **重播按钮**（右上角，z-50）：
  - `Button variant="ghost"` 半透明（`opacity-60 hover:opacity-100`）
  - `RotateCcw` 图标 + "重播故事"
  - 故事打断后仍可见

- **全屏点击拦截层**（z-40）：
  - 透明 `<div>` 全屏覆盖，`cursor-pointer`
  - 点击 → `pause()` → 故事打断

- **脉冲高亮控件**：
  - 被 `highlightControl` action 指定的控件：`animate={{ scale: [1, 1.06, 1] }}` + 蓝色光晕（`boxShadow` 呼吸）
  - 2 秒周期循环

- **导航栏锁定**：非故事按钮 `disabled`（故事运行期间禁止手动切换模式）
- **打断后**：3 秒自动消失的 Toast"故事已暂停 · 点击探索"

### 故事状态机

| 当前状态 | 触发事件 | 下一状态 | 副作用 |
|----------|----------|----------|--------|
| `idle` | 用户点击故事模式 | `intro` | 切换到 story 模式 → 执行 intro `onEnter` → 字幕显示 → rAF 启动 → 拦截层挂载 → 导航锁定 |
| 任意阶段 | `elapsed >= nextPhase.startTime` | 下一阶段 | 执行当前阶段 `onExit` → 执行下一阶段 `onEnter` → 字幕切换 |
| `climax` | `elapsed >= 210s` | `finished` | 字幕消失 → `storyEnd` 事件 → `setMode(previousMode)` → 导航恢复 |
| 任意运行中 | 用户点击画面 | `当前阶段`（暂停） | `isInterrupted=true` → 字幕消失 → `storyInterrupted` 事件 → 导航恢复 |
| 任意 | `replay()` | `intro` | 重置所有参数 → 停止蝴蝶/反演/声效 → 重新 `start()` |

## 六、模式切换时的状态行为

| 组件 | 卸载时 | 挂载时 | 备注 |
|------|--------|--------|------|
| 3D Canvas（EXP-01） | WebGL 上下文释放，当前帧保留在 RingBuffer | 从 RingBuffer 最新位置恢复，1-2 帧内恢复显示 | GPU 资源释放 |
| 2D 图表（ANL-*） | Canvas DOM 移除，数据保留在 Zustand store | 从 store 读取数据重新绘制（~16ms） | 无数据丢失 |
| CodeMirror（LAB-03） | DOM 移除，代码文本保留在 store | 编辑器重建 + `doc.setText(store.code)` | 光标回到开头 |
| 参数面板（SIM-02） | React 树卸载，参数保留在 store | 从 store 恢复所有滑块位置 | 无感知 |
| Web Audio（EXP-03） | OscillatorNode 保持运行（全局单例） | 重新订阅 store | 无中断 |
| **Worker（SIM-01）** | **不卸载**（全局单例，独立于 React 生命周期） | **无变化** | 仿真持续运行 |

**键盘快捷键**：纯数字键 `1` `2` `3` `4` 切换模式。焦点在 `<input>` / `<textarea>` 内时忽略，含修饰键（Ctrl/Alt/Meta/Shift）时忽略。

## 十、设计文档未覆盖的必要补充

以下页面/状态在设计文档中未明确提及，但对完整的用户体验必不可少：

| 补充项 | 必要性 | 设计方案 |
|--------|--------|---------|
| **分析模式数据加载骨架** | 预计算 JSON 可能需数百 ms 加载 | Canvas 区域渲染 shadcn/ui `Skeleton` 占位，带"正在加载预计算数据…"文本 |
| **分析模式无数据降级** | SYS-03 预计算加载失败 | Tab 内容区显示空状态："离线模式：该分析功能需预计算数据支持"，提供"返回探索模式"按钮 |
| **庞加莱截面空状态** | 某些参数下轨迹不穿过截面 | Canvas 内居中显示"当前参数下轨迹可能不穿过所选截面，建议更换截面条件" |
| **物理验证首次进入引导** | 用户可能不知道从何开始 | 3 个验证卡片默认 `idle`（灰色），卡片描述文字说明验证内容与通过标准 |
| **实验报告生成失败** | Canvas 截图需 `preserveDrawingBuffer: true` | 失败时 `Alert`："截图失败，请检查浏览器兼容性或刷新后重试" |
| **故事模式首次引导** | 用户可能未发现故事模式 | 故事模式导航按钮非激活时显示 `animate-pulse`，首次点击后永久停止（localStorage 记录） |
| **浏览器后台恢复提示** | 切标签页时系统自动暂停仿真 | 页面中央短暂 Toast："已暂停，点击继续"（3 秒后消失） |
| **长时间运行降级提示** | 仿真 > 10 分钟 | 自动降低积分精度与尾迹长度 + Toast："已进入长效运行模式" |
| **演示模式入口** | STY-02 纯净视图一键隐藏所有 UI | 所有模式右上角提供"演示模式"按钮（`EyeOff` 图标），点击一键切换纯净视图；再次点击或 Esc 退出 |
| **全局键盘快捷键提示** | 用户可能不知道快捷键 | 导航栏图标 `Tooltip` 中已包含快捷键提示（如"快捷键 1"），无需额外面板 |

## 十一、视觉风格关键词

基于设计文档的隐含美学定位，提取以下视觉方向：

- **材质对比**：金属（高反射冷光）、木质（漫反射暖色）、玻璃（半透明透光）三种摆体材质
- **科学可视化色阶**：D3 发散色阶（深蓝→青绿→橙红），用于 Lyapunov 热力图和速度尾迹
- **电影式字幕**：衬线字体（`font-serif`），底部居中，`backdrop-blur` 半透明背景，暗示科学纪录片
- **脉冲高亮**：蓝色光晕呼吸动画（`boxShadow` 0→6px→0），暗示"这里可以交互"
- **状态色彩编码**：绿色=通过/正常、红色=失败/发散、黄色=警告/运行中、灰色=未激活/idle
- **空间纵深**：3D 场景的上帝俯视与混沌跟随视角差异，暗示"从不同尺度观察同一系统"
- **A4 学术报告**：实验报告模仿高校物理实验报告排版，暗示教学严肃性
