> 面向对象：大学物理小组作业成员

> 你需要知道的关于本项目的一切，都在这里。

## 一、一句话概括

**这是一个在浏览器里运行的"双摆混沌实验室"——你不需要安装任何软件，打开网页就能看到双摆运动、听到混沌的声音、分析非线性系统的行为。**

---

## 二、这个项目是做什么的？

简单说，我们做了一个**交互式的双摆物理仿真系统**。

双摆（Double Pendulum）是物理学中最经典的混沌系统之一。它只有两个摆锤，却能展现出极其丰富的动力学行为——从优雅的周期运动到完全不可预测的"混沌"状态。

我们的系统让你可以：

| 你能做什么 | 具体来说 |
|-----------|---------|
| 🎮 **动手玩** | 拖拽滑块改变摆的质量、长度、初始角度，实时看到 3D 双摆在动 |
| 👂 **听到混沌** | 系统把角度、角速度、动能转化成声音——混沌状态听起来像"碎裂"的噪音 |
| 🔬 **分析数据** | 查看能量变化曲线、相空间轨迹、Lyapunov 指数热力图、分岔图、庞加莱截面 |
| 🦋 **蝴蝶效应实验** | 并排两个几乎一样的双摆（初始角度差仅 0.000001°），观察它们如何逐渐走向完全不同 |
| ⏪ **时间反演** | 让时间倒流，看双摆能不能"回到过去"——混沌系统的数值不可逆性 |

---

## 三、为什么选"双摆"作为课题？

双摆是一个"麻雀虽小，五脏俱全"的非线性动力学系统：

- **方程简单**：只有两个广义坐标 θ₁、θ₂，运动方程可以手推
- **现象丰富**：周期运动、准周期运动、混沌，全都有
- **物理深刻**：涉及拉格朗日力学、能量守恒、初值敏感性、Lyapunov 指数、分岔理论
- **可视化漂亮**：3D 摆锤运动 + 彩色尾迹，一眼就能看出"有序 vs 混沌"

> 评委看到不会觉得"这只是在放动画"——背后是严格的物理公式和数值积分。

## 四、系统的四个模式

我们设计了四个递进的模式，对应从"感知"到"创造"的认知阶梯：

```
感知层（探索模式）→ 分析层（分析模式）→ 验证层（实验模式）→ 创造层（故事模式）
```

### 探索模式 —— "看见混沌"

- 3D 实时渲染的双摆，可以旋转、缩放、切换视角
- 彩色运动尾迹：蓝色 = 慢，红色 = 快
- 声音化引擎：把摆的运动实时变成声音
- 蝴蝶效应分屏对比：两个几乎一样的摆，渐行渐远

### 分析模式 —— "理解混沌"

- **Lyapunov 指数热力图**：一眼看出哪些参数组合会产生混沌（红色 = 混沌，蓝色 = 稳定）
- **分岔图**：观察参数连续变化时，系统行为如何突然"突变"
- **庞加莱截面**：在四维相空间中取一个截面，把连续的混沌轨迹变成离散的点集
- **能量景观**：3D 势能曲面 + 实时光点，看到摆在"能量山"上如何滑行

### 实验模式 —— "验证混沌"

- **物理验证套件**：一键验证小角度近似、能量守恒、单摆退化——给出"通过/不通过"绿色徽章
- **受力拆解**：实时显示重力、张力、惯性力的矢量箭头
- **实验报告生成**：一键导出 A4 PDF，包含参数表、截图、数据分析、物理结论

### 故事模式 —— "讲述混沌"

- 7 个阶段、3 分 30 秒的自动演示
- 电影式字幕讲解
- 适合在答辩/展示时直接播放

## 五、技术实现（给懂技术的人）

| 维度 | 方案 |
|------|------|
| 运行环境 | 纯浏览器客户端，零后端，离线可用 |
| 前端框架 | React 18 + TypeScript |
| 3D 渲染 | Three.js（React Three Fiber），60fps 实时 |
| 2D 图表 | D3.js 绘制分岔图、庞加莱截面、热力图 |
| 物理计算 | 自实现 RK4/RK45 积分器，跑在 Web Worker 中不卡界面 |
| 声音合成 | Web Audio API，角度→音高、动能→音色 |
| 状态管理 | Zustand，全局共享仿真数据 |
| 可编程沙箱 | Pyodide（浏览器里的 Python）+ SciPy，用户可以写自己的运动方程 |

**核心亮点**：物理引擎是纯数学计算，没有用到任何游戏引擎的物理模拟——每一步积分都是严格按照双摆的运动方程算出来的。

## 六、我们小组需要做什么？

这个项目是一个**软件开发 + 物理验证**的综合性作业。各成员可以根据自己的兴趣分工：

| 角色 | 适合的人 | 主要任务 |
|------|---------|---------|
| 📐 **物理担当** | 物理系的同学 | 推导并验证运动方程的正确性、设计物理回归测试、编写物理原理说明文档 |
| 🎨 **前端/可视化** | 会写代码的同学 | 3D 场景搭建、UI 界面开发、图表绘制 |
| 🎵 **声音化设计** | 有兴趣的同学 | 设计角度→音高的映射方案、实现听觉混沌标记 |
| 📝 **文档/展示** | 擅长表达的同学 | 项目文档撰写、PPT 制作、答辩演示、故事脚本编写 |
| 🧪 **测试/质量** | 细心的同学 | 物理回归测试、跨浏览器兼容性测试、找 bug |

> **不用担心"我不会写代码"**——物理部分（公式推导、验证标准、原理解释）本身就是一个完整的贡献方向。

## 七、项目的"加分项"

在小组答辩时，这些是我们的亮点：

1. **不是玩具**：背后是严格的拉格朗日力学 + Runge-Kutta 数值积分，物理老师看了会点头
2. **能动手**：评委可以亲自拖滑块、调参数，而不是只看 PPT
3. **有声音**：把混沌"听觉化"是非常新颖的角度，绝大多数物理仿真都不会做这个
4. **离线可用**：不需要联网、不需要安装，U 盘拷贝就能运行
5. **蝴蝶效应**：用肉眼看到"初始条件差亿分之一，最终结果完全不同"，非常有说服力
6. **可编程**：如果时间允许，支持用户自己写 Python 方程——这是一个"创造层"

## 八、快速上手

### 如果你只想看看效果

1. 打开项目目录下的 `dist/index.html`（或让懂代码的同学帮你启动开发服务器）
2. 右上角选择模式：探索 → 分析 → 实验 → 故事
3. 在探索模式中，拖拽左侧的参数滑块，看 3D 双摆的变化
4. 试试把初始角度调到 ~120°，你会看到混沌

### 如果你要参与开发

```bash
# 先装环境
pnpm install

# 启动开发服务器
pnpm dev

# 编辑器打开 src/features/ 目录，各功能模块都在里面
```

## 十、常见问题

**Q：这个项目难吗？**
