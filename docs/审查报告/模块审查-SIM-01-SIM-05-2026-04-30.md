**能量投影（`projectEnergy`）**：
- 设计文档未要求此功能
- 在保守系统（damping=0）时自动启用，每步校正能量漂移
- 增强了长期仿真的能量守恒精度

**庞加莱截面穿越检测**：
- 设计文档未要求此功能（设计文档注释说明 ANL-03 在 Worker 内直接消费状态向量）

#### 2.2.3 resetToDefaults 语义变更详解

```typescript
resetToDefaults: () => {
  // params 保留用户设置，不覆盖  ← 新增行为

    initialConditions: { ...DEFAULT_INITIAL_CONDITIONS },
    method: DEFAULT_METHOD,
    ...
  });

```

- 用户通过滑块调整的质量/杆长/重力/阻尼在重置时被保留

- **2 个测试失败**：`params.test.ts:170` 和 `phaseSpace.test.ts:195` 期望 `params.m1 === 1`，实际为修改后的值

### 3.3 联动问题详情

- 🟡 **SIM-02 Bridge 未暴露 workerReady 给 UI**：`bridge.ts:30-33` 维护了 `setWorkerReady()`/`setWorkerNotReady()` 但未同步到 store 或 UI 可消费的状态。ParamPanel 无法感知 Worker 是否就绪，导致应用初始加载时控件可交互但操作无效。
- 🟢 **SIM-04 / SIM-05 rAF 轮询 vs subscribe**：两者均通过独立的 rAF 循环读取 store（`getState()`），而非使用 Zustand subscribe 驱动。SIM-04 v1.0 审查的 M2 曾指出此问题。实际影响微小（< 1 帧延迟），但架构上偏离设计文档要求。
