## 四、发现的问题与风险

### 🔴 严重：无

### 🟡 中等

**M1: Worker 未就绪时缺少 "仿真引擎初始化中..." 提示**

- **位置**：`ParamPanel.tsx`
- **设计文档要求**（异常 2，第 675-678 行）：Worker ready 前，控制面板顶部显示 "仿真引擎初始化中..." 提示，所有滑块 disabled
- **当前代码**：`ParamPanel.tsx` 仅检查 `engineError !== null` 做 disable，不感知 Worker ready 状态。bridge.ts 中维护了 `workerReady` 标志但未暴露给 UI 层
- **影响**：应用初始加载时（Worker 尚未 ready），用户看到可交互的参数面板但操作无效
- **建议修复**：在 store 或 bridge 中将 `workerReady` 暴露给 UI（如 `isWorkerReady` 字段），ParamPanel 据此显示骨架屏/提示文字 + 禁用控件

**M2: PresetButtons 缺乏 Toast 通知**

- **位置**：`PresetButtons.tsx:17-22`
- **设计文档要求**（步骤 6，第 388 行；步骤 12，第 608 行）：
  - 成功时："已应用预设：{preset.label}"
  - 失败时："预设 '{label}' 参数校验失败：{error.message}"
- **当前代码**：失败时仅 `console.error`，成功时无任何用户反馈
- **影响**：用户点击预设后无视觉确认，不确定操作是否生效
- **建议修复**：配合 SYS-02 toast 通知系统实现（或使用 store 的 `engineEvent` 同款机制），成功/失败均显示短暂通知

**M3: 角度值缺少度数辅助显示**

- **位置**：`ParamSlider.tsx` — theta1/theta2 的显示
- **设计文档要求**（注意事项 2，第 822-823 行）："控制面板上对用户显示的角度值应以度（°）为单位...在滑块旁显示度数转换值作为辅助标签"
- **当前代码**：所有字段统一以 store 中的 rad 值显示，theta1/theta2 的 `unit` 显示为 `"rad"`
- **影响**：用户（尤其教学场景的学生）难以直观理解"1.5708 rad = 90°"的含义
- **建议修复**：在 ParamSlider 中对 group === "initial" 且 key 为 theta1/theta2 的字段，在 Label 或 unit 旁附加 `(≈{deg}°)` 转换显示

### 🟢 轻微

**L1: ParamSlider Slider `disabled` 使用静态 getState()**

- **位置**：`ParamSlider.tsx:83` — `disabled={useSimulationStore.getState().engineError !== null}`
- **问题**：`getState()` 是静态快照，组件不会因 `engineError` 单独变化而重渲染。需等其他 selector 触发重渲染时才反映新 disabled 状态
- **建议修复**：改为 `const engineError = useSimulationStore((s) => s.engineError); disabled={engineError !== null}`

**L2: `applyPreset` 返回类型与设计文档不一致**

- **位置**：`store.ts:249` — 返回 `string | null`，设计文档定义为 `void`
- **影响**：返回值实际被 `PresetButtons` 正确消费（检查 err 做日志），是合理的改进。建议更新设计文档或确认此为有意偏离

### 总体评价

SIM-02 的落地质量高。10 字段的校验体系（hardMin/hardMax/sliderMin/sliderMax/decimalPlaces 五维约束）完整实现，6 个 store action 严格遵循 error→冻结/warning→允许/pass→静默的三级分流，ParamSlider 双模式（Slider+Input）交互正确。Bridge 层的 16ms 防抖合并与 Worker ready 命令队列设计合理。16 个测试覆盖了所有 action 的正向和 4 个异常场景。

主要缺口集中在 UI 层的边界体验：Worker 初始化期间的 loading 态缺失、操作反馈 toast 未接入、角度单位的教学友好显示。这三个问题不影响仿真核心功能，但在评审演示中会降低用户体验的完备感。
