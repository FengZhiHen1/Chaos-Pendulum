## 二、P0 — 核心骨架（无此不成作品）：9 个模块

### 仿真核心与全局控制

| 模块 | 名称 | 工期 | 说明 |
|:---|:---|:---|:---|
| **SIM-01** | 双摆物理引擎 | 核心 | JS Worker + RK4/RK45 + Transferable Float64Array 池 + 批量积分 (每次 2s/120 帧 @60fps) |
| **SIM-02** | 参数控制面板 | 核心 | ≥8 参数 (m₁/m₂/L₁/L₂/θ₁/θ₂/θ̇₁/θ̇₂/g/damping) 滑块+数值输入双模式 + 校验拒绝 |
| **SIM-03** | 全局导航系统 | 核心 | 4 模式 (探索/分析/实验/故事) 一键切换 + 响应式导航栏 + 键盘快捷键 1-4 + Error Boundary |
| **SIM-04** | 能量实时监控 | 2 天 | E_k + E_p 实时曲线 + 相对漂移百分比 + 1000s 漂移 <0.5% 告警 |
| **SIM-05** | 相空间可视化 | 2 天 | θ-θ̇ 2D 相平面 Canvas 实时轨迹 + θ₁/θ₂ 变量对切换 |

### 探索模式

| 模块 | 名称 | 工期 | 说明 |
|:---|:---|:---|:---|
| **EXP-01** | 3D 仿真场景 | 核心 | R3F + drei — 3 种视角 (实验员/上帝/混沌) + 3 种材质 (金属/木质/玻璃) + 2 种环境 (暗室/纯白) |
| **EXP-02** | 运动尾迹渲染 | 核心 | 速度→颜色映射 (静止蓝→高速红) + 尾迹粗细随速度 + 5 种持久度 + 冻结旋转观察 |
| **EXP-04** | 蝴蝶效应对比器 | 核心 | 左右双独立 Viewport (金色 A / 紫色 B) + δ=10⁻⁶° + 分离度 \|Δθ\|>90° 脉冲提示 |

### 分析模式

| 模块 | 名称 | 工期 | 说明 |
|:---|:---|:---|:---|
| **ANL-03** | 庞加莱截面 | 2-3 天 | Worker RK45 穿越检测 + 线性插值 + 2D 散点图动态生长 + 当前/历史轨线叠加 |

## 四、SYS — 系统基础能力：4 个模块

| 模块 | 名称 | 说明 |
|:---|:---|:---|
| **SYS-01** | 响应式布局引擎 | 桌面三栏 (左控制+中 3D+右图表) / 平板底部抽屉 / 手机单栏聚焦 3D — 所有模块的布局容器依赖 |
| **SYS-02** | 运行时异常处理 | 代码超时→行号高亮+中文翻译 / 预计算加载失败→离线模式提示 / 切后台→自动暂停 / >10min→自动降级 |
| **SYS-03** | 预计算数据管线 | Python 脚本离线生成 Lyapunov 谱 + 分岔图 JSON → IndexedDB 缓存 → ANL-01/ANL-02 按需加载 |
| **SYS-04** | 应用初始化加载 | Pyodide ~18MB 下载进度条 (百分比+已下载/总量) + 预计剩余时间 + 离线重试 + 加载完成平滑过渡 |

## 五、INF — 基础设施与运维（并行）：3 个模块

| 模块 | 名称 | 说明 |
|:---|:---|:---|
| **INF-01** | 应用可观测性 | FPS 帧率追踪 + Worker 耗时 + Pyodide 加载状态 + 全局错误捕获 (window.onerror/unhandledrejection) → Zustand debug store |
| **INF-02** | 持续部署管线 | GitHub Actions 三阶段：代码检查 (tsc/ESLint) → 测试 (Vitest + 物理回归) → 构建 (Vite + Pyodide 打包) → 部署 |
| **INF-03** | 自动化测试体系 | 物理回归 (小角度 <2% / 单摆退化周期吻合 / 能量漂移 <0.5%) + 预计算数据 hash 校验 + UI 组件测试 |

## 八、模块依赖关系速查

```
                    ┌─────────────┐
                    │  SIM-01     │ ← 双摆物理引擎 (最底层)
                    │  (Worker)   │
                    └──────┬──────┘
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ EXP-01   │    │ SIM-04   │    │ SIM-05   │
    │ 3D 场景  │    │ 能量监控 │    │ 相空间图 │
    └────┬─────┘    └──────────┘    └──────────┘
    ┌────┴─────┐
    ▼          ▼
┌────────┐ ┌────────┐
│EXP-02  │ │EXP-04  │
│尾迹渲染│ │蝴蝶效应│
└────────┘ └────────┘

EXP-03 (声音化) ──消费──▶ SIM-01 Zustand Store
EXP-05 (时间反演) ──消费──▶ SIM-01 Worker setDirection(-1)
ANL-03 (庞加莱) ──消费──▶ SIM-01 Worker RK45
ANL-01/ANL-02 ──消费──▶ SYS-03 (预计算管线)
STY-01 ──编排──▶ SIM-02 (参数) + EXP-01 (3D) + EXP-04 (分屏) + SIM-03 (模式切换)

所有模式组件 ──依赖──▶ SIM-03 (AppShell 布局容器)
所有模块 ──依赖──▶ SYS-01 (响应式) + SYS-02 (异常处理) + SYS-04 (初始化)
```
