# 《双摆混沌实验室》第二版功能设计文档

**版本**：V2.0 — "物理认知平台"  
**定位**：从"可交互仿真"升级为"浏览器内的非线性动力学研究终端"  
**核心主张**：让混沌不仅被看见，还能被听见、被拆解、被编程、被验证

---

## 一、设计理念升级

### 1.1 设计哲学
第一版回答"双摆怎么动"，第二版回答"人类如何认知混沌"。作品不再是一个动画播放器，而是一个**分层递进的物理认知工具**：

- **感知层**：3D 视觉 + 实时声效，建立直觉
- **分析层**：分岔图 + 李雅普诺夫谱 + 庞加莱截面，建立定量
- **验证层**：时间反演 + 受力拆解 + 能量景观，建立因果
- **创造层**：可编程方程 + 实验报告，建立迁移

### 1.2 目标用户分层
| 层级 | 用户 | 使用方式 | 作品应对 |
|------|------|---------|---------|
| 公众 | 非专业参观者 | 看故事模式、听声音变化 | 零门槛感官冲击 |
| 学生 | 本科物理/工科生 | 调参数、做实验、出报告 | 教学闭环 |
| 教师 | 理论力学/计算物理教师 | 验证公式、展示概念 | 科研级分析工具 |
| 评委 | 竞赛评审专家 | 3 分钟快速理解深度 | 故事模式一键演示 |

## 三、探索模式（Explore）：实时仿真与感官认知

### 3.1 3D 主场景（升级）
- **视角系统**：支持鼠标/触控旋转缩放；提供"实验员视角"（固定侧视）、"上帝视角"（俯视）、"混沌视角"（跟随末端球运动）
- **实体渲染**：摆球大小与质量正相关；摆杆粗细与刚度相关；材质区分金属/木质/玻璃（仅视觉，不影响物理）
- **环境氛围**：可选暗色实验室背景（聚光灯打在摆上）或纯白教学背景

### 3.2 运动尾迹系统（升级）
- **速度-色彩映射**：尾迹颜色由末端球瞬时速度决定（静止蓝 → 高速红）
- **尾迹厚度映射**：速度越高尾迹越粗，形成"速度热力"效果
- **尾迹持久度**：短（50步）、中（200步）、长（1000步）、无限、以及**"仅保留当前周期"**（用于观察周期轨道闭合）
- **尾迹冻结**：暂停时尾迹定格，支持 360° 旋转观察其空间几何结构

### 3.3 声音化系统（Sonification）—— 新增核心差异
**设计目标**：让混沌从"可见"变为"可听"。

- **音高映射**：下摆球角速度 $\dot{\theta}_2$ 映射为基频（周期运动 → 稳定音高；混沌运动 → 无规则音高跳跃）
- **和声映射**：两杆夹角映射为和声复杂度（夹角稳定 → 纯五度和谐；夹角剧烈变化 → 增加不协和音程）
- **能量映射**：系统总动能映射为音色亮度（低动能 → 柔和正弦波；高动能 → 明亮锯齿波）
- **混沌听觉标记**：当李雅普诺夫指数估算值 > 0 时，自动混入轻微白噪声与混响，形成"声音碎裂"效果
- **静音切换**：控制面板提供"开启物理声效"按钮，默认关闭（避免评审现场嘈杂）

### 3.4 蝴蝶效应对比（升级）
- **分屏视图**：左右两个独立 3D 视口，分别展示"摆 A"（金色）与"摆 B"（紫色）
- **差异溯源面板**：显示两摆的初始差异 $\delta$（可精确到 $10^{-6}$ 度），以及当前角度分离度 $|\Delta\theta|$
- **分离警报**：当 $|\Delta\theta| > 90^\circ$ 时，屏幕中央出现 subtle 脉冲提示"完全失相关"
- **同步控制**：两摆的播放/暂停/重置完全同步；调节参数时可选"仅调节 A""仅调节 B"或"同步调节"

### 3.5 时间反演实验 —— 新增核心差异
**设计目标**：揭示混沌与数值计算的本质关系。

- **操作入口**：显著位置的"时间倒流"按钮，带沙漏图标
- **执行逻辑**：系统以当前状态为初值，反向积分 ODE（$dt \to -dt$），理论上应回到起点
- **视觉对比**：
  - 实线：时间反演后的实际轨迹
  - 虚线：理论上应精确重合的原轨迹（从尾迹历史数据中调取）
- **误差可视化**：两线分离的过程实时展示；屏幕侧边显示"数值漂移距离"曲线
- **教学注释**：分离发生时，自动弹出注释框："哈密顿系统理论上可逆，但混沌使计算机的浮点误差被指数放大——这就是初值敏感性的计算物理体现"
- **可配置参数**：用户可选择"精确反演"（使用历史状态插值，理论上完全重合，用于对照）或"数值反演"（重新积分，展示误差累积）

## 四、分析模式（Analyze）：科研级诊断工具

### 4.1 参数空间李雅普诺夫指数谱
- **数据基础**：预计算二维参数网格（如 $L_2/L_1$ 比 × 初始角 $\theta_1$），每个格点存储估算的最大李雅普诺夫指数 $\lambda_{max}$
- **可视化**：Canvas 2D 热力图，色阶为 深蓝（$\lambda < 0$，稳定）→ 青绿（$\lambda \approx 0$）→ 橙红（$\lambda > 0$，混沌）
- **交互**：
  - 鼠标悬停显示精确 $\lambda$ 值与对应参数
  - 点击格点自动将该组参数填充至控制面板并启动 3D 仿真
  - 支持热力图与 3D 场景的**双向联动**：在 3D 中调节参数时，热力图上的游标实时移动
- **图层切换**：支持切换不同物理量的扫描图层（能量曲面曲率、最大 Lyapunov、最小 Lyapunov）

### 4.2 参数空间分岔图（Bifurcation Diagram）
- **数据基础**：固定其他参数，扫描单一控制参数（如 $\theta_1$ 或 $L_2$），记录系统稳态后某状态变量（如 $\theta_2$ 的局部极大值集合）
- **可视化**：横轴为扫描参数，纵轴为状态变量采样点。周期区呈现离散点/线，混沌区呈现连续带
- **交互**：
  - 竖直游标可拖拽，位置对应当前 3D 仿真的参数设定
  - 点击混沌带中的某一点，自动设定参数并播放，观察对应运动形态
  - 支持框选放大，观察周期倍增通向混沌的细节

### 4.3 庞加莱截面（Poincaré Section）—— 准实时
- **截面定义**：默认截面为 $\theta_1 = 0$ 且 $\dot{\theta}_1 > 0$（上摆垂直向上穿越）；用户可自定义截面条件（如 $\theta_2 = \pi/2$）
- **采样机制**：Web Worker 在实时积分过程中检测截面穿越事件，用线性插值精确求解穿越点坐标 $(\theta_2, \dot{\theta}_2)$
- **可视化**：2D 散点图，横轴 $\theta_2$，纵轴 $\dot{\theta}_2$
- **动态生长**：点随时间逐步添加，用户可观察"从离散点 → 闭合曲线 → 奇怪吸引子"的演化过程
- **对比模式**：支持叠加显示"当前轨线"与"历史基准轨线"的截面点，用不同颜色区分

### 4.4 能量景观地形图（Energy Landscape）—— 新增
- **可视化**：3D 半透明曲面，高度映射双摆势能 $V(\theta_1, \theta_2)$，颜色映射势能梯度
- **实时光点**：当前摆的状态 $(\theta_1, \theta_2)$ 在曲面上投射一个发光小球，随运动滑动
- **等高线投影**：曲面底部投射势能等高线，帮助识别势阱与势垒
- **教学价值**：直观解释"为什么某些初始条件下系统被困在周期轨道（势阱深），某些条件下能翻越能垒进入混沌漫游"

## 五、实验模式（Lab）：教学闭环与创造

### 5.1 白盒受力拆解（动态自由体图）—— 新增
**触发方式**：3D 场景中点击"受力分析"按钮，或按空格键暂停后自动进入。

- **力矢量叠加**：
  - 重力 $m\vec{g}$：绿色箭头，固定竖直向下
  - 杆张力 $\vec{T}$：红色箭头，沿杆方向
  - 惯性力分量：蓝色虚线箭头，分解为切向与法向
- **数值标签**：鼠标悬停每个箭头，显示力的大小（N）与方向角
- **分量分解面板**：右侧显示当前时刻的力分解表格（切向/法向/径向），支持切换坐标系（笛卡尔 / 极坐标 / 自然坐标）
- **历史极值**：自动标记本次仿真中张力的最大值与最小值，提示"何时最接近失重/超重"

### 5.2 物理验证套件 —— 新增
提供三个一键验证实验，证明仿真物理正确性：

| 验证项 | 操作 | 预期结果 | 通过标准 |
|--------|------|---------|---------|
| 小角度线性化 | 一键将两摆设为 3° 以内 | 叠加显示理论简谐解（虚线） | 数值解与理论解偏差 < 2% |
| 单摆退化 | 一键将 $m_2 \to 0$ | 系统退化为单摆 | 周期与 $T=2\pi\sqrt{L_1/g}$ 吻合 |
| 能量守恒 | 一键关闭阻尼，长时间运行 | 总能量曲线水平 | 1000s 内相对漂移 < 0.5% |

验证通过时显示绿色徽章"物理模型验证通过"；不通过时自动提示检查步长设置。

### 5.3 用户可编程仿真（浏览器内沙箱）—— 新增
**设计目标**：从"使用给定模型"到"创造物理模型"。

- **代码编辑器**：界面内嵌轻量代码编辑区，支持 Python 语法高亮
- **可修改范围**：用户可重写运动方程函数，例如：
  - 将刚性杆改为弹簧连接（引入弹性系数 $k$）
  - 加入周期性驱动力（受迫混沌）
  - 修改势能函数（如加入磁场洛伦兹力项）
- **安全边界**：
  - 白名单 import（仅允许 numpy 及标准库子集）
  - 执行超时限制（5 秒）
  - 错误捕获与友好提示（行号标注 + 常见错误词典）
- **即时反馈**：修改代码后点击"运行"，3D 场景立即切换至新模型，保留当前视角与参数面板
- **预设模板**：提供"弹簧摆""受迫摆""磁力摆"三个模板代码，用户基于模板修改

### 5.4 一键实验报告生成 —— 新增
**触发**：实验模式下的"导出报告"按钮。

- **报告内容自动生成**：
  - 实验标题与目的（基于当前预设场景或用户输入）
  - 参数设置表（含数值与单位）
  - 关键帧截图（自动选取 4 个时刻：初始、中期、分离/混沌、稳态）
  - 数据图表（能量图、相空间图、时序图）
  - 物理结论（基于当前李雅普诺夫指数的混沌判定语句）
  - 误差分析（能量守恒偏差、数值方法说明）
- **格式**：标准 A4 PDF，排版模仿高校物理实验报告模板
- **元数据**：页脚自动附加作品名称、团队署名、生成时间戳

## 六、故事模式（Story）：评审专用演示

### 6.1 一键故事模式
**入口**：全局导航栏显著位置的"播放故事"按钮。

**脚本编排（总时长 3 分 30 秒，可中途打断）**：

| 时间 | 场景 | 画面 | 旁白字幕 |
|------|------|------|---------|
| 0:00-0:25 | 引入 | 暗色背景，单摆稳定摆动 | "一个摆，我们知道它会在哪里" |
| 0:25-0:50 | 升级 | 加入第二根杆，运动开始复杂 | "再加一个摆，世界变得不可预测" |
| 0:50-1:30 | 蝴蝶效应 | 分屏对比，两摆从重合到分离 | "初始差异仅 0.001°，30 秒后它们形同陌路" |
| 1:30-2:00 | 声音化 | 开启声效，从和谐音阶到噪声 | "混沌不仅能看见，还能听见" |
| 2:00-2:30 | 分析工具 | 切换到分析模式，展示分岔图与热力图 | "这不是随机，是有结构的复杂" |
| 2:30-3:00 | 时间反演 | 执行倒流实验，轨迹无法重合 | "甚至计算机也无法让混沌回头" |
| 3:00-3:30 | 升华 | 回到 3D 场景，尾迹填满空间 | "确定性系统的内在随机性——这就是混沌" |

- **自动转场**：每个阶段自动切换模式、调节参数、旋转视角
- **字幕系统**：屏幕底部出现电影式字幕，解释物理概念
- **高亮引导**：当前交互的按钮/滑杆自动脉冲发光，暗示"这里可以操作"
- **打断机制**：点击任意位置暂停故事，进入手动探索；提供"重播故事"按钮

### 6.2 演示模式（评审大屏优化）
- **纯净视图**：一键隐藏所有控制面板、图表、导航栏，仅保留 3D 场景与必要指标
- **自动巡游**：无人操作时，视角以 0.5°/s 缓慢环绕，持续展示运动美感
- **水印署名**：3D 场景角落显示团队名称与作品名，截图分享时自动附带

## 七、数据与记录系统

### 7.1 状态快照
- 用户可随时保存快照，记录完整参数、运行状态、尾迹历史
- 快照以缩略卡片排列，显示关键参数与缩略图
- 支持快照对比：选择两个快照，系统自动生成参数差异表，并支持轨迹叠加显示

### 7.2 数据导出
- **CSV 时序数据**：导出角度、角速度、坐标、能量、时间戳的完整表格
- **JSON 场景文件**：导出可分享的参数文件，其他用户导入即可复现
- **图像导出**：支持导出当前 3D 视图、相空间图、分岔图、庞加莱截面的 PNG（4K 分辨率）

### 7.3 回放与分叉
- 暂停状态下，时间轴可拖拽回溯历史
- 支持"从历史时刻分叉"：选择过去某一时刻，修改一个参数后继续演化，原轨迹以半透明保留作为对照

## 八、响应式与跨端策略

| 端 | 布局策略 | 功能降级 |
|----|---------|---------|
| 桌面（主要） | 三栏：左控制、中 3D、右图表；分析模式全屏 | 无降级，完整功能 |

## 九、异常处理与边界设计

| 用户行为 | 系统响应 |
|---------|---------|
| 输入非物理参数（负质量/零摆长） | 输入框红框震动拒绝，悬浮提示合理范围；3D 场景冻结直至参数合法 |
| 用户编程代码超时/报错 | 捕获异常，行号高亮，侧边显示友好错误翻译（如 "IndexError → 数组越界，请检查维度"） |
| 长时间运行（> 10 分钟） | 自动降低积分精度与尾迹长度，提示"已进入长效运行模式" |
| 庞加莱截面长期无穿越 | 提示"当前参数下轨迹可能不穿过所选截面，建议更换截面条件" |
| 预计算数据加载失败 | 优雅降级：提示"离线模式：高级分析功能需预计算数据支持"，保留实时仿真 |
| 浏览器后台运行 | 自动暂停仿真与声音化，切回时提示"已暂停，点击继续" |
