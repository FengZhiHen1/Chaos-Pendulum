## 原始叙述
> 此模块吸收旧设计中的 LAB-01（受力拆解视图）、LAB-02（物理验证套件）、LAB-03（用户可编程沙箱）、LAB-04（实验报告生成器）四个模块。
>
> 合并理由：四者构成完整的"物理教学闭环"——受力拆解（理解为什么这么动）→ 物理验证（证明动得对）→ 可编程沙箱（改规则看看会怎样）→ 实验报告（把发现写下来交作业）。四者在实验模式页面中共存，报告生成器消费前三者的数据和截图。
>
> **旧设计原文摘录**（功能设计_v0.md）：
> - LAB-01: 在 3D 场景中可视化叠加作用于双摆的力矢量及其分量分解。3 种力矢量叠加（重力绿色/张力红色/惯性力蓝色虚线）；鼠标悬停显示力大小（N）+ 方向角；分量分解面板支持 3 种坐标系切换（笛卡尔/极坐标/自然坐标）；自动标记本次仿真张力最大/最小值时刻。
> - LAB-02: 一键运行三个标准物理验证实验。小角度线性化（偏差 < 2%）、单摆退化（周期吻合 T=2π√(L₁/g)）、能量守恒（1000s 漂移 < 0.5%）；通过时显示绿色徽章"物理模型验证通过"；不通过时自动提示检查步长设置。
> - LAB-03: 提供浏览器内 Python 代码编辑器，允许用户修改运动方程并即时生效。Python 语法高亮编辑器；白名单 import（numpy + 标准库子集）；执行超时 5s；报错时行号高亮 + 中文错误翻译；3 个预设模板（弹簧摆/受迫摆/磁力摆）；修改代码运行后 3D 场景立即切换至新模型。
> - LAB-04: 自动整理实验数据并生成标准 A4 PDF 格式的物理实验报告。自动生成 6 项内容（标题与目的/参数设置表/4 关键帧截图/数据图表/物理结论/误差分析）；自动选取 4 个关键帧；排版模仿高校物理实验报告模板；页脚附带作品名+团队署名+生成时间戳。

## AI 提炼摘要
### 功能定位
双摆混沌实验室的"物理教学闭环"——从受力理解（为什么动）、到物理验证（动得对不对）、到规则修改（如果规则不同会怎样）、到报告生成（把探索结果写成实验报告），让产品从"可交互仿真"升级为"可交作业的教学工具"。

### 目标用户
- 学生（本科物理/工科生）：使用完整教学闭环完成一次从调参到写报告的学习过程
- 教师：利用物理验证套件在课堂上证明仿真的正确性，用受力拆解讲解多体动力学
- 评委：验证套件的绿色徽章提供"物理正确性背书"，可编程沙箱展示工程炫技

### 核心场景
1. **受力分析教学**：教师暂停仿真 → 点击"受力分析"按钮 → 3D 场景叠加三色力矢量（重力/张力/惯性力）→ 鼠标悬停显示力的大小和方向 → 切换坐标系演示不同分解方式 → 自动高亮张力最大/最小时刻
2. **一键物理验证**：教师点击"物理验证"按钮 → 三项验证依次自动运行（小角度线性化/单摆退化/能量守恒）→ 全部通过后显示绿色徽章"物理模型验证通过"→ 不通过时自动提示检查步长设置
3. **学生编程实验**：学生打开代码编辑器 → 选择"弹簧摆"模板 → 修改弹簧劲度系数 k 的值 → 点击运行 → 3D 场景从双摆切换为弹簧连接的双摆 → 学生观察弹簧刚度如何影响混沌行为
4. **一键交作业**：学生完成实验探索 → 点击"导出报告" → 系统自动生成 A4 PDF 实验报告（参数表 + 4 张关键帧截图 + 能量/相空间图表 + 混沌判定 + 误差分析）→ 页脚附带作品名和生成时间戳

### 关键功能点
- **受力拆解视图**：3 种力矢量叠加渲染（重力绿色 / 张力红色 / 惯性力蓝色虚线）；鼠标悬停显示力大小（N）+ 方向角；分量分解面板支持 3 种坐标系切换（笛卡尔 / 极坐标 / 自然坐标）；自动标记本次仿真张力最大值/最小值（"最接近失重/超重"）
- **物理验证套件**：3 项一键验证——小角度线性化（数值解 vs 理论简谐解偏差 < 2%）、单摆退化（m₂→0 时周期吻合 T=2π√(L₁/g)）、能量守恒（1000s 内相对漂移 < 0.5%）；三态结果（idle/running/passed/failed）；全部通过显示绿色徽章 + "物理模型验证通过"；不通过时自动提示检查步长设置
- **用户可编程沙箱**：CodeMirror 6 Python 语法高亮编辑器；白名单 import（numpy + 标准库子集）；执行超时 5 秒（Pyodide）；报错时行号高亮 + 中文错误翻译（如 IndexError→"数组越界，请检查维度"）；3 个预设模板（弹簧摆 / 受迫摆 / 磁力摆）；运行后 3D 场景立即切换至新模型
- **实验报告生成器**：一键生成 A4 PDF（jsPDF + autoTable）；自动填充 6 项内容（标题与目的 / 参数设置表 / 4 关键帧截图 / 能量图+相空间图 / 混沌判定结论 / 误差分析）；自动选取 4 个关键帧（初始 / 中期 / 分离或混沌 / 稳态）；排版模仿高校物理实验报告模板；页脚附带作品名+团队署名+生成时间戳

### 边界与约束
- **P2 优先级**：教学实验套件整体为 P2 推荐选做，物理验证套件（LAB-02）投入产出比最高优先做，可编程沙箱（LAB-03）工程复杂度最高（Pyodide + CodeMirror + 安全沙箱）可放到最后
- **可编程沙箱安全边界**：仅白名单 import，禁止文件系统和网络访问；超时中断不可绕过
- **报告生成依赖截图 API**：3D 场景需 `preserveDrawingBuffer: true` 才能 `toDataURL()`，若关闭则截图降级为空
- **不做在线判分**：不提供自动评分或答案检查功能

### 依赖项
- 仿真引擎与3D场景（消费状态向量、力分量 Worker 扩展、3D Canvas 截图）
- 参数面板与模式导航（实验模式页面入口）
- 动力学分析工具（实验报告的混沌判定依赖 Lyapunov 指数）
- Pyodide 运行时（可编程沙箱依赖）
- CodeMirror 6（代码编辑器依赖）
