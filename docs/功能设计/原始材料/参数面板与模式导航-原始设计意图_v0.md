## 原始叙述
> 此模块吸收旧设计中的 SIM-02（参数控制面板）和 SIM-03（全局导航系统）两个模块。
>
> 合并理由：参数面板和模式导航是用户与系统交互的"控制面"——参数调的是当前模式的仿真，模式切换决定的是显示哪个功能区域。两者在界面层面紧密耦合（导航栏中切换模式的同时可能需要注入预设参数），且在响应式布局中联动（平板/手机的参数面板和导航栏共用底部抽屉空间）。
>
> **旧设计原文摘录**（功能设计_v0.md）：
> - SIM-02: 管理双摆全部物理参数与初始条件的输入、调节与合法性校验。管理 ≥ 8 个参数（m₁, m₂, L₁, L₂, θ₁, θ̇₁, θ₂, θ̇₂, g, 阻尼）；滑块+数值输入双模式；非法参数输入时红框震动拒绝并悬浮提示合理范围，3D 场景冻结直至参数合法。
> - SIM-03: 管理四种工作模式的一键切换与跨模式仿真状态保持。4 种模式（探索/分析/实验/故事）；导航栏在所有页面始终可见；切换模式时保持当前仿真运行状态不中断。

## AI 提炼摘要
### 功能定位
用户与双摆混沌实验室的"控制面"——提供全部物理参数的输入、调节与校验，管理四种工作模式的一键切换与跨模式状态保持，以及适配桌面/平板/手机三端的响应式布局外壳。

### 目标用户
- 学生/教师：频繁调参观察运动变化，是最活跃的控制面使用者
- 评委：通过导航栏快速切换模式，故事模式是评审入口
- 公众：仅需最基本的播放/暂停和视角操作
- 所有用户：移动端访问时自动获得适配布局

### 核心场景
1. **连续参数即时生效**：用户拖动 m₁/m₂/L₁/L₂/g/damping 滑块 → Worker 在下一步积分时自动使用新值，仿真不中断 → 3D场景中摆体大小、杆长即时变化，运动模式随之连续演变 → 能量曲线和相空间图历史数据保留
2. **初始条件参数带预览 + 松手复位**：用户拖动 θ₁/θ̇₁/θ₂/θ̇₂ 滑块 → 3D场景中叠加一个**半透明静态预览摆**停留在新初值位置（仿真继续运行在旧初值上）→ 松手瞬间：预览摆实体化 → Worker Reset → 尾迹清空 → 从新初值重新开始积分。预览消除了"Slider值≠画面"的认知割裂，Reset 的跳变被预览阶段缓冲
3. **模式切换与状态保持**：用户在四种模式间点击导航Tab（或按键盘1-4）→ 内容区切换至对应功能页面 → 仿真在后台持续运行不中断 → 切回探索模式时看到3D场景仍然在运动
4. **故事模式自动锁定**：故事自动播放中 → 导航栏锁定，用户无法手动切换模式 → 故事结束或用户点击打断 → 导航栏恢复，自动回到之前的模式

### 关键功能点
- **参数输入系统**：管理 ≥10 个参数（m₁, m₂, L₁, L₂, θ₁, θ̇₁, θ₂, θ̇₂, g, damping）；滑块拖拽 + 数值精确输入双模式；预设管理（快速加载预定义参数组）；`injectParams` 静默注入接口（供热力图点击等场景调用）
- **参数分类响应策略**：连续参数（m₁/m₂/L₁/L₂/g/damping）拖拽即时生效，Worker 不重启，尾迹和图表历史保留；初始条件参数（θ₁/θ̇₁/θ₂/θ̇₂）拖拽时 3D 场景叠加半透明静态预览摆，松手后触发 Worker Reset + 尾迹清空，从新初值重启积分
- **合法性校验**：非法参数（负质量/零摆长/角度超范围）→ 输入框红框震动拒绝 + 悬浮Tooltip提示合理范围；3D 场景冻结（isSceneFrozen）直至参数合法
- **四模式导航栏**：4 种模式（探索/分析/实验/故事），全局始终可见；键盘快捷键 1-4 切换；活跃模式高亮；故事模式期间锁定（含脉冲动画引导）
- **跨模式状态保持**：切换模式时仿真不中断、不停机；Worker 持续运行，所有可视化组件的 Store 订阅不受影响
- **响应式布局适配**：桌面（三栏：左控制面板 + 中3D场景 + 右图表区）；平板（控制面板收纳为底部抽屉，图表Tab切换，关闭声音化）；手机（单栏聚焦3D场景，高级功能折叠，关闭阴影与尾迹，禁用编程编辑器）

### 边界与约束
- **仅做输入合法性校验，不做物理合理性判断**：例如 m₁=0.0001kg 在技术上合法，但物理上可能导致数值不稳定，这属于用户探索范畴
- **不做智能参数推荐**：不提供"推荐参数"或"混沌参数发现"功能（属于动力学分析工具的范畴）
- **导航栏始终可见但可被演示模式隐藏**：故事模式的演示模式（STY-02 原模块）请求隐藏导航栏时，本模块配合执行
- **响应式断点固定**：≥1024px 桌面、768-1023px 平板、<768px 手机
- **连续参数与初始条件参数分轨处理**：连续参数（m₁/m₂/L₁/L₂/g/damping）拖拽时禁止 Worker Reset，仅更新 ODE 右侧函数参数值；初始条件参数（θ₁/θ̇₁/θ₂/θ̇₂）拖拽时禁止即时 Reset——必须等用户松手后才执行 Worker Reset + 尾迹清空 + 重启积分。拖动过程中 3D 场景必须叠加半透明静态预览摆以消除 Slider 值与画面状态的认知割裂

### 依赖项
- 仿真引擎与3D场景（读写仿真参数和运行状态）
- 后续四个功能模块（均通过模式切换激活）
