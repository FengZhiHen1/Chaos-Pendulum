## 原始叙述
> 此模块吸收旧设计中的 STY-01（故事脚本引擎）、STY-02（演示模式）、DAT-01（状态快照）、DAT-02（数据导出）、DAT-03（历史回放与分叉）五个模块。
>
> 合并理由：演示和数据管理共享"时间轴操控"这一核心能力——故事模式是按时间轴自动执行动作序列，历史回放是按时间轴手动回溯，快照是保存时间轴上某一时刻的完整状态，数据导出是时间轴上积累的数据输出。五者统一管理应用的状态持久化和时序控制。
>
> **旧设计原文摘录**（功能设计_v0.md）：
> - STY-01: 按预设时间轴自动执行 7 阶段演示序列，实现一键科普讲解。7 阶段脚本编排，总时长 3 分 30 秒；阶段间自动转场（切换模式/调节参数/旋转视角）；底部电影式旁白字幕；任意位置点击暂停故事并切换手动探索。
> - STY-02: 为评审大屏场景提供纯净视图与自动巡游。一键隐藏所有控制面板、图表与导航栏；无人操作时视角以 0.5°/s 自动环绕；3D 场景角落显示团队名称与作品名水印。
> - DAT-01: 一键保存与恢复完整仿真状态，支持快照对比。快照记录完整参数、运行状态与尾迹历史；以缩略卡片排列；支持双快照参数差异表自动生成与轨迹叠加显示。
> - DAT-02: 将仿真数据与可视化结果导出为多种可分享格式。支持 3 种格式：CSV 时序数据、JSON 场景文件（可分享复现）、PNG 截图（最高 4K）。
> - DAT-03: 支持沿时间轴回溯历史状态，并从任意历史时刻分叉演化。暂停状态下时间轴可拖拽回溯；支持选择过去某一时刻，修改参数后从该点继续演化；原轨迹以半透明保留作为对照。

## AI 提炼摘要
### 功能定位
双摆非线性动力学虚拟仿真实验的"记忆与表演"层——故事模式提供评审专用的一键自动演示，演示模式提供大屏纯净展示，数据快照/导出/回放与分叉提供完整的数据生命周期管理。统一处理应用的时间轴操控和状态持久化。

### 目标用户
- 评委：故事模式一键自动演示（3分30秒）是评审体验的核心触点；演示模式的大屏纯净视图适配评审现场
- 学生/教师：数据导出和快照功能支持实验记录和作业提交
- 公众：故事模式的科普讲解提供零门槛理解入口

### 核心场景
1. **评审一键演示**：评委坐到大屏前 → 用户点击"播放故事"按钮 → 7阶段自动演示（3分30秒）——从单摆引入到时间反演升华 → 底部电影式字幕同步讲解物理概念 → 当前可操作控件自动脉冲高亮 → 演示结束或评委点击打断后恢复手动探索
2. **大屏自动巡游**：评审现场长时间无人操作 → 自动进入演示模式 → 隐藏所有UI控件 → 视角以0.5°/s缓慢环绕 → 3D场景角落显示团队水印 → 任何人触碰控件立即恢复完整界面
3. **实验记录与复现**：学生探索到一个有趣的混沌运动 → 点击"保存快照" → 系统保存完整参数+状态+尾迹 → 继续调参探索 → 随时可加载之前保存的快照恢复那个状态 → 选择两个快照自动生成参数差异表对比
4. **时间轴回溯与分叉**：学生想"如果当时参数不同会怎样"→ 暂停仿真 → 拖拽时间轴回溯到某个历史时刻 → 修改一个参数 → 从该时刻继续演化 → 原轨迹以半透明幽灵尾迹保留作为对照

### 关键功能点
- **故事脚本引擎**：7 阶段预设时间轴（总时长 3 分 30 秒）；每阶段定义时长/目标模式/参数/相机/字幕/脉冲高亮控件；自动转场（setMode/injectParams/setCamera/startButterfly）；底部电影式字幕（framer-motion 淡入淡出）；当前可交互控件脉冲高亮引导；点击任意位置暂停→切换手动探索 + 提供重播按钮；故事播放期间导航栏锁定（storyPhase→SIM-03 消费）；storyEnd/storyInterrupted 事件派发
- **演示模式**（评审大屏优化）：一键隐藏所有控制面板/图表/导航栏；OrbitControls autoRotate 0.5°/s 自动环绕；3D 场景角落水印（团队名称 + 作品名）；触碰任意控件恢复完整 UI
- **状态快照**：一键保存完整仿真状态（参数 + StateVector + 尾迹历史 + 缩略图）；IndexedDB 存储（键 `snapshot-{uuid}`，LRU 上限 50）；缩略卡片列表展示关键参数与64px缩略图；双快照对比——自动生成参数差异表 + 轨迹叠加显示
- **数据导出**：3 种格式导出——CSV（14 字段时序数据：角度/角速度/坐标/能量/时间戳）、JSON（场景文件：PendulumParams + trajectory，可分享复现）、PNG 截图（3D 视图/相空间图/分岔图/庞加莱截面，最高 4K 分辨率）
- **历史回放与分叉**：暂停状态时间轴可拖拽回溯（基于 RingBuffer 随机访问）；选择历史时刻 → 修改参数 → 分叉 Worker 实例（初始条件 = ringBuffer.at(t)）；原始轨迹以半透明幽灵尾迹叠加保留作为对照

### 边界与约束
- 故事模式 P1 优先级（评审体验关键），数据管理 P3 优先级（锦上添花）
- 快照存储上限 50 个（IndexedDB 空间限制 + 管理复杂度）
- RingBuffer 容量 6000 帧（=100s @60fps），回溯范围限于此窗口内
- 大屏演示模式的自动巡游在用户交互后立即停止，不自动恢复
- 数据导出不包含视频/动画格式（不做 MP4/GIF 录屏）
- JSON 场景文件仅包含参数和轨迹，不包含尾迹历史（数据量过大）

### 依赖项
- 仿真引擎与3D场景（Worker 实例管理、RingBuffer 回溯、3D Canvas 截图、OrbitControls）
- 参数面板与模式导航（setMode 锁定/解锁、injectParams、导航栏隐藏）
- 混沌现象探索（故事脚本可能触发蝴蝶效应和声音化）
- 动力学分析工具（分岔图/庞加莱截面的 Canvas 截图）
