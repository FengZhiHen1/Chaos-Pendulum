## 原始叙述
> 此模块吸收旧设计中的 LAB-01（受力拆解视图），从原「教学实验套件」中独立拆分。
>
> 拆分理由：受力拆解是独立的 3D 可视化叠加层，不依赖物理验证的结果，也不依赖可编程沙箱。它解决的是单一问题——"此刻摆球受到哪些力？这些力如何分解？"——具有独立的教学展示价值。
>
> **旧设计原文摘录**（功能设计_v0.md）：
> - LAB-01: 在 3D 场景中可视化叠加作用于双摆的力矢量及其分量分解。3 种力矢量叠加（重力绿色/张力红色/惯性力蓝色虚线）；鼠标悬停显示力大小（N）+ 方向角；分量分解面板支持 3 种坐标系切换（笛卡尔/极坐标/自然坐标）；自动标记本次仿真张力最大/最小值时刻。

## AI 提炼摘要
### 功能定位
在 3D 场景中叠加力矢量可视化，将双摆系统内部的力学关系从"看不见"变为"叠在摆上看得见"——让学生和教师直观理解多体动力学中的重力、张力和惯性力如何共同决定摆的运动。

### 目标用户
- 学生（本科物理/工科）：理解拉格朗日力学中广义力的物理含义
- 教师（理论力学）：在课堂上叠加力矢量讲解多体动力学，展示不同坐标系下的力分解
- 评委：力矢量叠加展示作品的教学深度

### 核心场景
1. **受力分析教学**：教师暂停仿真 → 点击"受力分析"按钮 → 3D 场景中摆球和摆杆上叠加三色力矢量箭头 → 重力（绿色）固定竖直向下，张力（红色）沿杆方向，惯性力（蓝色虚线）分解为切向与法向 → 鼠标悬停任意箭头显示力的大小（N）与方向角
2. **坐标系切换对比**：学生打开分量分解面板 → 默认笛卡尔坐标系看力的 (x, y) 分量 → 切换到极坐标看径向/切向分量 → 切换到自然坐标看沿轨迹的法向/切向分量 → 对比同一力在不同坐标系下的分解差异
3. **极值追踪**：仿真持续运行 → 系统自动追踪并标记本次仿真中张力的最大值/最小值时刻 → 教师指向标记点说"这里摆球最接近失重""这里张力最大"

### 关键功能点
- **力矢量叠加渲染**（R3F Canvas叠加层）：3 种力矢量——重力（绿色箭头，固定竖直向下）、杆张力（红色箭头，沿杆方向，大小随运动变化）、惯性力分量（蓝色虚线箭头，分解为切向与法向）
- **悬停数值标签**：鼠标悬停任意力矢量箭头 → 显示力的大小（N）+ 方向角（°）
- **分量分解面板**：右侧面板显示当前时刻的力分解表格；支持 3 种坐标系切换——笛卡尔（x, y 分量）、极坐标（径向/切向）、自然坐标（沿轨迹法向/切向）
- **极值自动标记**：自动追踪本次仿真中张力的最大值/最小值时刻，在时间轴上打标记提示"最接近失重"或"张力最大"

### 边界与约束
- 力矢量是纯可视化叠加，不改变物理引擎的任何计算
- 力分量的计算在 Worker 中完成，通过扩展协议发送力分量数据
- 悬停交互仅在桌面端可用（移动端缺少 hover 能力，降级为始终显示数值标签）
- 不做力的动画/过渡效果——力矢量随每一帧直接更新位置和大小

### 依赖项
- 仿真引擎与3D场景（Worker 力分量数据输出、共享 R3F Canvas）
- 参数面板与模式导航（实验模式页面入口）
