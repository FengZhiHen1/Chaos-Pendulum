## 原始叙述
> 此模块吸收旧设计中的 EXP-03（声音化引擎）、EXP-04（蝴蝶效应对比器）、EXP-05（时间反演实验）三个模块。
>
> 合并理由：三者都是"通过实验手段感知混沌特性"——声音化是用听觉感知混沌→秩序的转变，蝴蝶效应是用视觉感知初值敏感性，时间反演是用对比感知混沌的数值不可逆性。三者共享探索模式页面，共用仿真引擎的状态输出，在实现上也联动（蝴蝶效应分离时混入声音化噪声，时间反演复用蝴蝶效应的双轨迹叠加渲染）。
>
> **旧设计原文摘录**（功能设计_v0.md）：
> - EXP-03: 将双摆运动参数实时映射为音频，使混沌可听。4 维参数→音频映射（θ̇₂ 映射音高/两杆夹角映射和声/总动能映射音色/混沌时混入白噪声+混响）；默认静音，控制面板一键开启；含"声音碎裂"混沌听觉标记。
> - EXP-04: 双视口并排展示微小的初值差异如何导致轨迹分离。左右双独立 3D 视口（金色摆 A / 紫色摆 B）；初始差异 δ 精确至 10⁻⁶°；分离度 |Δθ| > 90° 时屏幕中央脉冲提示"完全失相关"；两摆播放/暂停/重置完全同步，参数调节支持单侧或同步。
> - EXP-05: 以当前状态为初值反向积分 ODE，可视化混沌的数值不可逆性。提供精确反演（历史插值）与数值反演（重新积分）两种模式；实线（实际轨迹）+ 虚线（理论轨迹）对比显示；实时绘制数值漂移距离曲线；分离时自动弹出哈密顿可逆性与浮点误差的教学注释。

## AI 提炼摘要
### 功能定位
混沌现象的"感官实验室"——通过听觉（声音化）、视觉比较（蝴蝶效应）和时间操纵（反演实验）三个维度，让用户直观体验混沌的三个核心性质：不可预测性、初值敏感性和数值不可逆性。

### 目标用户
- 公众/参观者：蝴蝶效应分屏是最直观的"混沌是什么"展示，声音化提供独特感官体验
- 学生：时间反演实验揭示数值计算与物理理论之间的张力，建立计算物理思维
- 评委：三者为第二版核心差异点，是作品深度的主要体现

### 核心场景
1. **听见混沌**：用户点击"开启物理声效" → 单摆稳定摆动时听到稳定音高 → 调参进入混沌后声音变得无规则跳跃，混入噪声和混响 → "声音碎裂"让混沌可被听见识别
2. **看见蝴蝶效应**：用户打开蝴蝶效应分屏 → 左右两个3D视口（金色摆A、紫色摆B）初始几乎重合 → 30秒内两摆轨迹剧烈分离 → 分离度超90°时屏幕脉冲提示"完全失相关" → 用户可调节初始差异 δ（小至10⁻⁶°）观察分离时间的变化
3. **时间倒流的失败**：用户点击"时间倒流"按钮 → 系统从当前状态反向积分 → 实线（实际反演轨迹）与虚线（原始正向轨迹）起初重合 → 数十秒后两线分离 → 漂移距离曲线展示误差指数增长 → 教学注释弹出解释混沌的数值不可逆性

### 关键功能点
- **参数→音频映射**（Web Audio API）：θ̇₂ 映射基频音高；两杆夹角映射和声复杂度（稳定→纯五度和谐，剧烈变化→不协和音程）；总动能映射音色亮度（低动能正弦波→高动能锯齿波）；混沌听觉标记——λ>0时自动混入白噪声+混响形成"声音碎裂"
- **默认静音 + 一键开关**：AudioContext 需用户手势激活，控制面板提供开关按钮，移动端（平板/手机）自动禁用
- **蝴蝶效应双视口**：左右独立 3D 视口（金色摆A / 紫色摆B）；初始差异 δ 精确至 10⁻⁶°；分离度 |Δθ| > 90° 脉冲提示"完全失相关"；两摆播放/暂停/重置完全同步；参数调节支持仅调A/仅调B/同步调三种模式
- **双 Worker 同步控制**：蝴蝶效应分裂出独立 Worker 实例运行偏离参数；主仿真可暂停/继续独立于蝴蝶分屏
- **时间反演双模式**：精确反演（使用历史 RingBuffer 插值回放，理论上完全重合，作对照组）；数值反演（Worker 以 -dt 重新积分，展示浮点误差累积）
- **反演轨迹可视化**：实线（实际反演轨迹）+ 虚线（原始正向历史轨迹）叠加对比；Canvas 2D 漂移距离曲线实时绘制
- **教学注释自动弹出**：分离发生时自动弹出注释框——"哈密顿系统理论上可逆，但混沌使计算机的浮点误差被指数放大——这就是初值敏感性的计算物理体现"

### 边界与约束
- 声音化默认静音（避免评审现场嘈杂），移动端自动禁用（扬声器限制）
- AudioContext 需用户手势激活（浏览器安全策略），不与自动播放冲突
- 蝴蝶效应启动时需明确主仿真的行为（暂停/继续），当前设计倾向主仿真继续运行
- 时间反演的"精确反演"模式受 RingBuffer 容量限制（6000帧=100s），超出部分无法插值
- 不做音频导出/录制功能

### 依赖项
- 仿真引擎与3D场景（消费状态向量、RingBuffer 历史、Worker setDirection 接口）
- 参数面板与模式导航（读当前模式、响应声音化开关的交互）
