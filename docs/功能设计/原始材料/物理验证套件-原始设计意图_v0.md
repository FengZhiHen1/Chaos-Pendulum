## 原始叙述
> 此模块吸收旧设计中的 LAB-02（物理验证套件），从原「教学实验套件」中独立拆分。
>
> 拆分理由：物理验证套件是唯一提供"物理正确性背书"的功能——它不展示教学内容，而是回答"这个仿真算得对不对"。三件套验证（小角度线性化/单摆退化/能量守恒）有独立的标准和断言逻辑，结果以绿色徽章形式输出供其他模块消费。
>
> **旧设计原文摘录**（功能设计_v0.md）：
> - LAB-02: 一键运行三个标准物理验证实验。小角度线性化（偏差 < 2%）、单摆退化（周期吻合 T=2π√(L₁/g)）、能量守恒（1000s 漂移 < 0.5%）；通过时显示绿色徽章"物理模型验证通过"；不通过时自动提示检查步长设置。

## AI 提炼摘要
### 功能定位
双摆非线性动力学虚拟仿真实验的"物理正确性背书"——提供三个一键运行的标准物理验证实验，以可复现的量化标准证明仿真的数值正确性，通过时输出绿色徽章供所有用户（尤其是评委和教师）确认"这个仿真可信"。

### 目标用户
- 教师：课堂上演示验证实验，证明仿真的物理正确性，建立学生对数值仿真的信任
- 评委：绿色徽章提供"物理模型验证通过"的权威背书
- 学生：理解"数值仿真的正确性需要验证"这一科研思维

### 核心场景
1. **一键验证通过**：教师点击"物理验证"按钮 → 三项验证依次自动运行（每项约 5-10 秒）→ 小角度线性化通过 ✓ → 单摆退化通过 ✓ → 能量守恒通过 ✓ → 屏幕显示绿色徽章 + "物理模型验证通过" → 教师对学生说"你们可以放心用这个工具做实验"
2. **验证不通过排查**：用户修改了积分方法或步长 → 点击验证 → 能量守恒不通过（漂移 > 0.5%）→ 系统提示"能量漂移超出阈值，建议减小积分步长或切换至 RKF45"→ 用户调整设置后重新验证通过

### 关键功能点
- **三项标准验证**：小角度线性化——一键将两摆角度设为 <3° → Worker 数值积分 → 叠加显示理论简谐解（虚线）→ 偏差 < 2% 视为通过；单摆退化——一键将 m₂→0 → Worker 积分 → 周期与 T=2π√(L₁/g) 吻合视为通过；能量守恒——一键关闭阻尼 → 1000s 仿真 → 相对漂移 < 0.5% 视为通过
- **四态结果**：每项验证独立状态机（idle → running → passed | failed）；全部通过显示绿色徽章 + "物理模型验证通过"文字
- **失败诊断提示**：不通过时自动分析可能原因（步长过大/积分方法精度不足/阻尼未关闭）并给出建议

### 边界与约束
- 三项验证是**标准场景**，不覆盖所有可能的参数组合——验证通过并不意味着"所有参数下仿真都正确"
- 验证期间 Worker 被独占（不能同时运行用户仿真和验证实验），验证结束后自动恢复用户参数和状态
- 不做持续监控——验证是手动触发的一次性实验，不是后台持续运行的守护进程
- 不做 Python 沙箱的正确性验证（可编程沙箱中的用户自定义模型不属于本模块验证范围）

### 依赖项
- 仿真引擎与3D场景（Worker 参数注入、状态重置、长时间运行接口）
- 参数面板与模式导航（验证入口、结果展示区域）
