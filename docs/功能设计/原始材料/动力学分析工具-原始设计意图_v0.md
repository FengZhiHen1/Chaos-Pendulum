## 原始叙述
> 此模块吸收旧设计中的 ANL-01（李雅普诺夫指数谱）、ANL-02（参数空间分岔图）、ANL-03（庞加莱截面）、ANL-04（能量景观地形图）四个分析模块，以及 SYS-03（预计算数据管线）一个支撑模块。
>
> 合并理由：五个模块构成完整的"非线性动力学诊断工具套件"——SYS-03 离线生成预计算数据（Lyapunov网格 + 分岔采样），ANL-01/02 消费预计算数据提供二维全局视图，ANL-03 消费实时 Worker 数据提供截面视图，ANL-04 消费实时状态提供能量结构视图。四者共享分析模式页面，预计算管线是前两者的唯一数据来源，不可拆分。
>
> **旧设计原文摘录**（功能设计_v0.md）：
> - ANL-01: 展示二维参数空间内最大李雅普诺夫指数的预计算热力图。二维参数网格（如 L₂/L₁ 比 × θ₁ 初始角）；Canvas 2D 热力图（深蓝 λ<0 稳定 → 橙红 λ>0 混沌）；悬停显示精确 λ 值与参数；点击格点自动填充参数并启动 3D 仿真；热力图与 3D 场景双向联动。
> - ANL-02: 沿单一参数维度扫描，展示系统稳态行为的分岔结构。固定其他参数，扫描单一控制参数；纵轴为状态变量采样点；竖直游标联动当前仿真参数；支持框选放大观察周期倍增细节。
> - ANL-03: 准实时采集截面穿越点，在 2D 散点图中展示轨道结构。默认截面 θ₁=0, θ̇₁>0；用户可自定义截面条件；Web Worker 实时检测截面穿越并用线性插值求解穿越点坐标；散点图动态生长展示"离散点→闭合曲线→奇怪吸引子"演化。
> - ANL-04: 3D 可视化双摆系统势能分布。3D 半透明曲面（高度映射 V(θ₁,θ₂)，颜色映射势能梯度）；实时光点标记当前状态；曲面底部投射势能等高线。
> - SYS-03: 离线生成李雅普诺夫谱与分岔图的预计算数据。本地 Python 脚本扫描参数网格并存储 λ_max 与分岔采样数据；前端按需加载预计算数据；加载失败时优雅降级为离线提示。

## AI 提炼摘要
### 功能定位
浏览器内的"非线性动力学诊断终端"——提供李雅普诺夫指数谱、分岔图、庞加莱截面和能量景观地形图四件套，让用户以科研级工具定量分析双摆系统的混沌特性，辅以离线预计算管线保障数据可用性。

### 目标用户
- 教师（理论力学/计算物理）：利用工具在课堂上展示非线性动力学核心概念
- 学生（本科物理/工科高年级）：学习李雅普诺夫指数、分岔理论、庞加莱截面等抽象概念的可视化直觉
- 评委：分析工具套件是作品"科研深度"的核心体现

### 核心场景
1. **从热力图到3D仿真**：用户查看 Lyapunov 指数热力图 → 鼠标悬停看到 λ>0 的混沌区域 → 点击一个格点 → 参数自动填充 → 自动切换到探索模式 → 3D场景以新参数运行，用户直接观察混沌运动
2. **追踪分岔路径**：用户浏览分岔图 → 拖动竖直游标沿参数轴移动 → 观察从单周期→周期倍增→混沌的过渡 → 框选放大周期倍增区域查看细节 → 点击混沌带的某个点启动仿真观察对应运动
3. **截面上的奇怪吸引子**：用户进入庞加莱截面视图 → 自定义截面条件 → Worker 实时检测穿越事件 → 散点图从离散点逐渐生长为闭合曲线或奇怪吸引子结构 → 保存当前截面为基线 → 修改参数后叠加对比
4. **势能曲面上滑行**：用户打开能量景观地形图 → 3D 半透明曲面展示 V(θ₁,θ₂) → 实时光点在曲面上随摆运动滑动 → 用户理解"为什么某些初值被困在周期轨道（势阱）而某些能翻越能垒进入混沌"

### 关键功能点
- **李雅普诺夫指数热力图**（预计算 + Canvas 2D）：二维参数网格预计算 λ_max 矩阵；发散色阶（深蓝 λ<0 稳定 → 橙红 λ>0 混沌）；3 种图层切换（λ_max / λ_min / 能量曲面曲率）；悬停 Tooltip 显示精确 λ 值与参数坐标；点击格点 → `injectParams` 填充参数 → `setMode("explore")` 切换到 3D 场景；双向联动——3D 中调参时热力图游标同步移动
- **参数空间分岔图**（预计算 + Canvas 2D）：单参数扫描采样；横轴扫描参数 / 纵轴状态变量采样点（θ₂ 局部极大值）；周期区离散点/线 → 混沌区连续带；竖直游标联动当前仿真参数；d3-zoom 框选放大观察周期倍增
- **庞加莱截面**（准实时 + Canvas 2D）：默认截面 θ₁=0, θ̇₁>0；用户可自定义截面条件（变量/目标值/穿越方向）；Worker 实时符号穿越检测 + 线性插值精确求解穿越点；2D 散点图增量动态生长 + alpha aging 历史点；当前轨线 / 历史基线轨线叠加对比；点数 >10000 自动截断保留最近 5000
- **能量景观地形图**（实时 + 3D R3F）：3D 半透明曲面（高度映射 V(θ₁,θ₂)，颜色映射势能梯度）；实时光点标记当前 (θ₁,θ₂) 在曲面上的位置；曲面底部 CanvasTexture 等高线投影
- **预计算数据管线**（离线 + 前端缓存）：离线 Python 脚本扫描参数网格；自实现 RKF45 Fehlberg 4(5) 积分器（与 JS Worker 一致）；输出 LyapunovGrid JSON（100×100 浮点矩阵 + 阻尼多切片）+ BifurcationData JSON（采样序列）；前端 IndexedDB 缓存（键 `{type}-{gridHash}`，LRU ≤10）；SHA-256 hash 校验数据完整性；加载失败 → 优雅降级为离线提示
- **分析与3D场景双向联动**：热力图/分岔图点击 → 自动填充参数 + 切换到探索模式；3D 场景中参数变化 → 分析图上游标实时跟踪

### 边界与约束
- **预计算数据 vs 实时计算**：Lyapunov 谱和分岔图为离线预计算（浏览器内实时计算 100×100 网格不可行），庞加莱截面和能量景观为实时计算
- **数据加载失败不阻断仿真**：预计算数据不可用时，实时仿真和3D场景完全不受影响，仅分析模式显示离线提示
- **点数上限**：庞加莱截面点总数 >10000 时自动截断保留最近 5000，防止 OOM
- **不做 3D 数据浏览器**：不提供原始预计算数据的表格浏览或编辑功能

### 依赖项
- 仿真引擎与3D场景（消费状态向量、Worker 截面检测接口）
- 参数面板与模式导航（`injectParams` 接口、模式切换 `setMode`）
- 离线预计算脚本（不依赖运行时，独立 Python 管线）
