## 附录 C：边界决策记录

1. **SIM-04 能量实时监控 与 ANL-04 能量景观地形图**：两者均涉及能量，但维度不同——SIM-04 追踪总能量随时间的一维标量（守恒检验），ANL-04 展示势能随两个角度变化的二维曲面（结构分析）。独立可估算、独立有价值，保持分离。
2. **SIM-05 相空间可视化 与 ANL-03 庞加莱截面**：两者均为状态空间可视化，但 SIM-05 展示全相空间轨迹（连续），ANL-03 展示特定截面上的离散采样点。庞加莱截面需要独立的截面检测算法与线性插值逻辑，属于不同的工程问题，保持分离。
3. **EXP-05 时间反演实验 与 SIM-01 双摆物理引擎**：时间反演依赖物理引擎的反向积分能力，但其核心价值在于误差可视化与教学注释，而非积分本身。两者可由不同工程师独立实现（物理引擎提供 -dt 接口，反演模块消费该接口），保持分离。
4. **SYS-02 运行时异常处理 不拆分**：代码超时、预计算加载失败、后台暂停三种异常均通过统一的通知/降级通道处理，拆分后会导致降级 UI 逻辑分散，保持为一个模块。
