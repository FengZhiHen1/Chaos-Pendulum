## 一、物理模型与算法

### 1.1 系统定义：平面理想双摆

本系统研究的物理对象为**平面理想双摆**（Planar Ideal Double Pendulum）：

- 两根质量不计的刚性杆，长度分别为 $L_1$、$L_2$
- 两个质点 $m_1$、$m_2$ 分别固定于两杆末端
- 上端支点固定，系统在竖直平面内运动
- 均匀重力场 $g$，方向竖直向下
- 可选线性粘滞阻尼（Viscous Damping），阻尼力矩 $\tau_i = -b\,\dot{\theta}_i$

广义坐标 $(\theta_1, \theta_2)$，$\theta = 0$ 对应杆竖直向下，逆时针为正。

### 1.2 运动方程推导

以悬挂点为原点、$y$ 轴向上，笛卡尔坐标到广义坐标的映射为：

$$
\begin{aligned}
x_1 &= L_1 \sin\theta_1,\quad y_1 = -L_1 \cos\theta_1 \\
x_2 &= x_1 + L_2 \sin\theta_2,\quad y_2 = y_1 - L_2 \cos\theta_2
\end{aligned}
$$

系统动能 $T$ 与势能 $V$：

$$
\begin{aligned}
T &= \frac{1}{2}m_1 L_1^2 \dot{\theta}_1^2 + \frac{1}{2}m_2\bigl[L_1^2\dot{\theta}_1^2 + L_2^2\dot{\theta}_2^2 + 2L_1 L_2\dot{\theta}_1\dot{\theta}_2\cos(\theta_2-\theta_1)\bigr] \\[0.5em]
V &= -(m_1+m_2)gL_1\cos\theta_1 - m_2 g L_2 \cos\theta_2
\end{aligned}
$$

由欧拉–拉格朗日方程导出，引入角度差 $\delta = \theta_2 - \theta_1$，经矩阵求逆得到角加速度的显式表达式——**本系统 ODE 右端函数直接实现了以下公式**（见 `derivatives.ts:35-68`）：

$$
\boxed{
\begin{aligned}
\ddot{\theta}_1 &= \frac{m_2 L_1 \dot{\theta}_1^2 \sin\delta\cos\delta + m_2 g \sin\theta_2 \cos\delta + m_2 L_2 \dot{\theta}_2^2 \sin\delta - (m_1+m_2)g\sin\theta_1}{L_1\bigl[m_1 + m_2\sin^2\delta\bigr]} - b\,\dot{\theta}_1 \\[1.2em]
\ddot{\theta}_2 &= \frac{-m_2 L_2 \dot{\theta}_2^2 \sin\delta\cos\delta + (m_1+m_2)\bigl(g\sin\theta_1\cos\delta - L_1\dot{\theta}_1^2\sin\delta - g\sin\theta_2\bigr)}{L_2\bigl[m_1 + m_2\sin^2\delta\bigr]} - b\,\dot{\theta}_2
\end{aligned}
}
$$

> **代码实现要点**：分母 $m_1+m_2-m_2\cos^2\delta$ 在极端参数组合下可能趋近于零，代码中以 `DENOM_EPSILON = 1e-12` 做近零保护。

### 1.3 退化验证

**单摆退化**（$m_2 \to 0$）：分母趋近 $m_1$，$\ddot{\theta}_1 \to -(g/L_1)\sin\theta_1$，退化为标准单摆方程。

**小角度线性化**（$|\theta_1|,|\theta_2| \ll 1$，$b=0$）：在 $(0,0)$ 处 Taylor 展开到一阶，得到耦合线性振动系统，存在两个正则模（Normal Modes）。

上述退化情形均已编码为物理验证套件的自动化测试场景。

## 二、数值积分方法

本系统实现了三种积分器，以**策略模式**（Strategy Pattern）组织，通过 `IIntegrator` 契约接口统一调用（`integrators.ts`）。

### 2.1 RKF45 自适应积分器（默认）

采用 **Fehlberg 4(5) 嵌入对**，Butcher 表系数直接编码（`integrators.ts:60-87`）。核心特性：

- **自适应步长控制**：每子步计算 4 阶与 5 阶估计的差值作为误差估计，以容差 `tol = 1e-7` 为标准动态调整步长
- **步长坍缩回退**：当误差持续超标导致 $h < 10^{-10}$ 时，自动退化为 Euler 子步避免死循环
- **方向感知**：支持正向（`dt > 0`）与反向（`dt < 0`）积分，为时间反演实验提供数值基础

RKF45 在 $\Delta t = 1/60\,\mathrm{s}$ 标称步长下，1000s 仿真能量漂移控制在 $0.5\%$ 以下。

### 2.2 Velocity Verlet 积分器

Velocity Verlet 是一种辛积分器变体。需要特别指出：其辛性（Symplecticity）严格依赖于**正则坐标** $(q, p)$ 的使用。本系统以 $(\theta, \dot{\theta})$ 为状态变量（而非正则动量 $p = \partial L/\partial \dot{\theta}$），因此 Velocity Verlet 在此并非"天然辛"的。实验中学生可观察到，其长时能量漂移甚至可能劣于 RKF45——这本身构成一个重要的教学点。

### 2.3 显式 Euler（教学对照）

局部截断误差仅 $O(\Delta t^2)$，且不满足辛结构。对于混沌双摆，数秒内即导致能量发散。保留此积分器作为"反面教材"，让学生直观体会低阶方法的局限性。

### 2.4 积分器对比的教学价值

| 积分器 | 局部误差阶 | 能量行为 | 教学用途 |
|--------|:--:|---------|---------|
| RKF45 | $O(\Delta t^5)$ | < 0.5% / 1000s | 生产级精度基准 |
| Velocity Verlet | $O(\Delta t^2)$ | 中等漂移 | 理解辛积分器与坐标选择 |
| Euler | $O(\Delta t^2)$ | 快速发散 | 反面教材 |

## 三、软件架构设计

### 3.1 分层架构

本系统采用**前端五层 Clean Architecture**，自底向上为：

```
Domain 层          → 实体/值对象/领域服务（ODE 右端函数、积分器、漂移计算器）
Application 层     → 无状态用例（BootSequence、SaveSnapshot、ExportData 等）
Infrastructure 层  → 端口实现（Worker 调度器、IndexedDB 缓存、音频引擎、导出器）
ViewModel 层       → Zustand Store + 自定义 Hooks（状态管理与业务逻辑编排）
View 层            → React 组件（纯渲染，不含业务逻辑）
```

**依赖方向铁律**：上层可依赖下层，反向绝对禁止。View 层不直接调用 API 或 Worker，全部通过 ViewModel 层 Hooks 间接消费数据。

### 3.2 仿真数据管线

```
┌──────────┐   postMessage    ┌──────────────┐   Transferable    ┌──────────┐
│  Store   │ ◄────────────── │  Worker       │ ◄─────────────── │   ODE    │
│ (主线程)  │   Float64Array   │ (独立线程)     │   Float64Array池  │  积分器   │
└────┬─────┘                  └──────┬───────┘                  └──────────┘
     │                               │
     │  Command Bus                  │  scheduler:prefetchBatch
     ▼                               ▼
┌──────────┐                  ┌──────────────┐
│ 3D 场景   │                  │ 批量积分缓存   │
│ 尾迹/能量 │                  │ (10×4000帧池) │
└──────────┘                  └──────────────┘
```

- **Web Worker 隔离**：ODE 积分在独立线程中执行，主线程永不阻塞
- **Transferable 零拷贝**：`Float64Array` 通过 `postMessage` 的 Transferable 机制传输，所有权转移而非内存复制
- **批量积分**：Worker 以 10 帧批次（`FRAMES_PER_BATCH`）为单位积分，预取阈值 `BATCH_PREFETCH_THRESHOLD = 5` 触发下一批次的异步准备
- **RingBuffer 历史**：容量 6000 帧（= 100s @ 60fps），循环覆盖，支持时间反演和历史回放的随机访问

### 3.3 Command Bus 解耦

跨模块通信通过 Command Bus 而非直接引用。关键命令举例：

| 命令 | 方向 | 作用 |
|------|------|------|
| `simulation:overrideState` | Store → Worker | 注入状态（蝴蝶效应、历史回放） |
| `scheduler:setDirection` | Explore → Worker | 切换积分方向（时间反演） |
| `scheduler:pause/resume` | UI → Worker | 暂停/恢复仿真 |
| `scheduler:prefetchBatch` | TimeReversal → Worker | 预取反向积分数据 |
| `lab:forceData` | Worker → Lab | 推送力分量数据 |

### 3.4 代码归属说明

按竞赛要求，明确区分：

| 类别 | 内容 |
|------|------|
| **自主编写** | ODE 右端函数、三种积分器（RKF45/VelocityVerlet/Euler）、Worker 调度器与批量积分管线、Command Bus 通信协议、RingBuffer 历史存储、能量监控（含投影校正算法）、相空间可视化渲染器、运动尾迹缓冲区与着色管线、蝴蝶效应双 Worker 同步控制器、时间反演状态机与漂移计算器、受力分解计算器（8 种力分量）、物理验证三项场景、庞加莱截面穿越检测、分岔图/Lyapunov 热力图的 Canvas 渲染引擎 |

## 四、交互设计逻辑

### 4.1 四模式递进架构

本系统的交互设计核心理念是**四层递进认知闭环**，四种工作模式通过键盘 1–4 一键切换：

| 模式 | 认知层级 | 核心交互 | 对应物理概念 |
|------|---------|---------|------------|
| **探索** | 感知 | 拖拽观察 3D 摆、调节参数、开启尾迹/声音/蝴蝶效应/时间反演 | 直观感受混沌运动 |
| **分析** | 理解 | 浏览 Lyapunov 热力图、缩放分岔图、观察庞加莱截面 | 定量分析混沌特征 |
| **实验** | 验证 | 运行物理验证、查看受力拆解、编写 Python 运动方程 | 验证物理正确性、自主建模 |
| **故事** | 展示 | 7 阶段自动演示、电影式字幕、点击打断后手动探索 | 教学展示与成果汇报 |

**跨模式状态保持**：模式切换时仿真不中断，确保分析工具读取的是连续的运动数据。

### 4.2 参数交互策略

系统管理 **≥10 个物理参数**（$m_1, m_2, L_1, L_2, \theta_1, \dot{\theta}_1, \theta_2, \dot{\theta}_2, g, b$），采用分类响应策略：

| 参数类别 | 交互行为 | 设计理由 |
|---------|---------|---------|
| **连续参数**（$m, L, g, b$） | 拖拽滑块**即时生效**，不重启 Worker | 这些参数仅改变 ODE 系数，无需重置状态 |
| **初始条件参数**（$\theta, \dot{\theta}$） | 拖拽时在 3D 场景中**半透明预览**摆的新位置；**释放时**才触发 Worker Reset + 清空尾迹 | 避免拖动过程产生大量无效历史帧，同时提供视觉反馈 |

**合法性校验**：非法参数（如负质量、零杆长）触发红色边框抖动 + tooltip 提示，3D 场景冻结直至合法。

### 4.3 响应式布局策略

| 设备 | 布局 | 策略 |
|------|------|------|
| 桌面（≥1024px） | 三栏：控制面板 | 3D 场景 | 图表面板 | 完整功能 |
| 平板（768–1023px） | 控制面板折叠为底部抽屉，图表 Tab 切换 | 减少球体分段、关闭阴影 |
| 手机（<768px） | 单栏聚焦 3D 场景，折叠高级功能 | 最少分段、无阴影、无尾迹 |

### 4.4 关键交互设计决策

**蝴蝶效应对比器**：
- 左右独立 3D Viewport（金色摆 A / 紫色摆 B）
- 初始差异 $\delta\theta_1$ 精确至 $10^{-6}$ 度（约 $1.7 \times 10^{-8}$ rad）
- 分离度超过 90° 时触发完全退相关脉冲提示
- 双 Worker 同步控制，确保两侧完全相同的积分条件

**时间反演实验**：
- **精确反演**（对照组）：直接回放 RingBuffer 历史帧，零误差
- **数值反演**（实验组）：Worker 以 $-dt$ 重新积分同一 ODE，浮点误差被混沌指数放大
- 实时漂移曲线（Canvas 2D）+ 三阶段叙事提示（重合期 → 分离期 → 发散期）
- Worker 预取机制：启动数值反演前异步准备反向积分数据，避免 UI 卡顿

**物理验证套件**：
- 三项一键验证，每项拥有独立四项状态机（idle → running → passed | failed）
- 全部通过显示绿色徽章，不通过自动诊断可能原因（步长过大 / 积分器精度不足 / 阻尼未关闭）

## 五、混沌特征分析方法

### 5.1 最大李雅普诺夫指数（Benettin 算法）

离线预计算采用标准 Benettin 算法，在参数空间 $(L_2/L_1, \theta_{1,0})$ 上生成 $100 \times 100$ 网格的 MLE 热力图。算法步骤：

1. 从初值出发，抛弃瞬态 $T_{\text{trans}}$
2. 引入微扰 $\delta\mathbf{x}$（$\|\delta\mathbf{x}\| = \delta_0 \ll 1$）
3. 并行积分参考轨线与扰动轨线一个周期 $\tau$
4. 测量距离 $d(t+\tau)$，累积对数 $\lambda \leftarrow \lambda + \ln(d/\delta_0)$
5. 重新归一化扰动方向，保持长度 $\delta_0$
6. 循环 3–5，最终 $\lambda_{\max} = \frac{1}{T}\sum_k \ln(d_k/\delta_0)$

**教学交互**：点击热力图任意单元格 → 对应参数组合一键注入仿真 Store → 切换到探索模式，实现"从理论图谱到 3D 直观运动"的无缝跳转。

### 5.2 分岔图（稳态采样法）

离线预计算：固定其他参数，令控制参数在区间上取 $N$ 个离散值，对每个值积分足够长时间后抛弃瞬态，记录稳态阶段 $\theta_2(t)$ 的所有局部极大值。

- 周期运动 → 有限个孤立点（清晰曲线）
- 混沌运动 → 点散布在整个区间（雾状带）

**教学交互**：竖直游标联动当前仿真参数，框选区域可放大，点击分岔点弹出确认对话框后注入参数。

### 5.3 庞加莱截面

选取截面 $\theta_1 = C$，穿越方向 $\dot{\theta}_1 > 0$。Worker 实时检测穿越事件，线性插值精确穿越点，Canvas 2D 动态生长散点图 + $\alpha$ 老化效果。自动截断至 10,000 点防止性能退化。

## 六、能量分析与守恒验证

### 6.1 能量计算

动能与势能由状态向量实时计算（与拉格朗日函数 $T$、$V$ 公式一致）：

$$
K = \tfrac{1}{2}m_1 L_1^2\dot{\theta}_1^2 + \tfrac{1}{2}m_2\bigl[L_1^2\dot{\theta}_1^2 + L_2^2\dot{\theta}_2^2 + 2L_1 L_2\dot{\theta}_1\dot{\theta}_2\cos(\theta_2-\theta_1)\bigr]
$$
$$
V = -(m_1+m_2)gL_1\cos\theta_1 - m_2 g L_2 \cos\theta_2
$$

### 6.2 能量漂移检测

相对漂移量 $\eta(t) = |E(t) - E(0)| / |E(0)|$ 作为积分器精度的量化指标。检测逻辑（`simulationSlice.ts:365-382`）：

- **常规判定**（$|E(0)| \geq 1.0\,\mathrm{J}$）：$\eta > 0.5\%$ 触发告警
- **低能量判定**（$|E(0)| < 1.0\,\mathrm{J}$）：改用绝对漂移 $> 0.05\,\mathrm{J}$ 触发告警
- **阻尼豁免**：$b > 0$ 时不触发告警（能量衰减是物理预期的）
- **告警锁存**：一旦触发，即使漂移恢复也不自动解除，需用户手动清除——防止"漂移瞬态"被忽略
- **能量投影校正**：长时间仿真（≥ 5 分钟）自动触发，以初始能量为基准校正累积数值误差
