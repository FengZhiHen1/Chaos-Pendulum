## 一、视频制作总览

### 1.1 视频定位

本视频的核心目标是：**在 10 分钟内，向评审专家展示本仿真平台的教学价值、科学严谨性和技术创新性**。

视频需要清晰传达三条叙事线索：

| 叙事线 | 核心信息 | 对应评分维度 |
|--------|---------|:--:|
| **物理线** | 从单摆到双摆→混沌现象→定量分析——完整认知阶梯 | 科学性（30 分） |
| **技术线** | RKF45 自适应积分→Worker 零拷贝→四层递进架构→纯客户端 | 先进性（30 分） |
| **教学线** | 参数实时调节→视觉反馈→物理验证→Python 沙箱创造 | 现实意义（20 分） |

### 1.2 时间分配建议

| 段落 | 内容 | 时长 | 累计 |
|------|------|:--:|:--:|
| 片头 | 作品名 + 3D 双摆动画 | 15 秒 | 0:15 |
| 第一段 | 探索模式 — 主界面与基本操作 | 1 分 30 秒 | 1:45 |
| 第二段 | 混沌现象高光 — 蝴蝶效应 + 声音化 | 1 分 30 秒 | 3:15 |

| 第五段 | 实验模式 — 物理验证 + Python沙箱 | 1 分 15 秒 | 6:45 |

### 1.3 录屏环境准备

**运行环境要求**：
- Chrome 90+ 或 Edge 90+ 浏览器
- Windows 10+ / macOS 11+
- 屏幕分辨率建议 **1920×1080**（16:9）
- 关闭浏览器书签栏、扩展图标，保持界面干净
- 系统通知设为"免打扰"，避免弹窗打断

**浏览器准备**：
1. 清除浏览历史，确保地址栏无自动补全（避免泄露个人信息）
2. 确认 WebGL 2.0 可用（访问 `chrome://gpu` 检查）
3. 关闭所有其他标签页
4. 将浏览器窗口调整为 1920×1080（可用开发者工具模拟）

**音频准备**：
- 使用外置麦克风录制旁白（不要用笔记本内置麦克风）
- 录制环境保持安静，关闭空调/风扇等背景噪声源
- 提前测试音量，确保波形峰值在 -12dB 到 -6dB 之间

**录屏软件建议**：
- OBS Studio（免费，支持高码率录制）
- 输出设置：MP4 容器，H.264 编码，码率 8-15 Mbps，30fps

### 场景 1：片头（0:00–0:15）

**画面设计**：黑底渐显 3D 双摆场景（探索模式），双摆处于混沌运动状态，金色运动尾迹在空间中婉转舞动。作品名以电影式字幕从底部淡入。

**【操作步骤】**

1. 打开仿真程序，确认已处于探索模式（键盘按 `1`）
2. 参数使用默认值（或选择一个视觉优美的混沌参数组合）：
   - `m₁ = 1.0 kg, m₂ = 1.0 kg, L₁ = 1.0 m, L₂ = 1.0 m`

3. 确认运动尾迹已开启，颜色映射模式为"速度→颜色"
4. 用鼠标旋转相机到一个斜 45° 的最佳观察角度
5. 开始录制，等待 5 秒让双摆运行进入美学最佳状态
6. 在后期制作中叠加作品名文字

**【旁白文案】**

> （前 5 秒无旁白，仅背景音乐 + 双摆运动画面）
>
> 双摆非线性动力学虚拟仿真实验——从确定性规则到混沌行为的探索之旅。

**【注意事项】**
- 片头画面要保持简洁，不要出现任何 UI 面板
- 可在录制前按 `Eye` 按钮进入演示模式隐藏 UI，录制开头后再退出
- 作品名务必在后期以字幕叠加，不要在浏览器地址栏或页面标题中出现个人信息
- 背景音乐：推荐选用无版权氛围音乐（如 Artlist / Epidemic Sound），音量低于旁白 12dB

### 场景 2：探索模式 — 主界面与基本操作（0:15–1:45）

**画面设计**：展示完整的探索模式主界面（三栏布局），通过参数拖拽、视角切换、尾迹开闭等操作，让观众理解这是"一个可以实时交互的物理仿真系统"。

#### 2.1 界面总览（0:15–0:35）

**【操作】**
1. 若在演示模式，按 `Eye` 退出，显示完整 UI
2. 镜头保持 3D 场景居中，用光标依次指向三个区域：
   - 左侧：参数控制面板（滑块 + 数值输入）
   - 中央：3D 双摆场景（Three.js 渲染）
   - 底部：能量监控曲线（动能 + 势能 + 总机械能）
3. 键盘按 `1`–`4` 各一次，展示四种模式在导航栏上的切换效果

**【旁白文案】**

> 本平台是一个纯浏览器端的非线性动力学虚拟仿真实验系统。主界面由三个区域构成：左侧是支持十个以上物理参数的实时调节面板，中央是三维实时渲染的双摆场景，底部是能量监控曲线。
>
> 系统包含四种工作模式——探索、分析、实验、故事——键盘一键切换，仿真不中断。我们从探索模式开始。

#### 2.2 参数调节演示（0:35–1:10）

**【操作】**
1. 鼠标拖动 `θ₁` 滑块，展示 3D 场景中摆杆位置随之半透明预览
2. 释放滑块，Worker 重置，双摆从新初始角开始运动
3. 拖动 `L₂`（下摆杆长）滑块——即时生效，不重置——展示连续参数的热更新特性
4. 将 `b`（阻尼系数）从 0 拖到 0.5——双摆运动逐渐衰减，尾迹从混沌变为收敛
5. 将阻尼归零，运动恢复混沌

**【旁白文案】**

> 参数面板采用分类响应策略：改变质量和杆长等连续参数时，仿真即时更新，不中断；改变初始角度时，先在三维场景中半透明预览，释放滑块后才触发重置。这保证了操作的流畅性和物理一致性。
>
> 引入阻尼后，我们可以看到混沌运动逐渐衰减为周期运动——双摆最终收敛到下平衡点。阻尼归零，混沌回归。

#### 2.3 视角切换与尾迹（1:10–1:30）

**【操作】**
1. 鼠标左键拖拽旋转 3D 视角——展示自由轨道旋转
2. 鼠标滚轮缩放——展示相机拉近拉远
3. 点击视角快捷按钮（顶视图/前视图/侧视图），各停留 2 秒
4. 关闭运动尾迹→重新开启——展示尾迹着色效果（蓝色＝慢速，红色＝高速）
5. 停留几秒观察尾迹在空间中编织的复杂图案

**【旁白文案】**

> 三维场景支持自由轨道旋转和缩放，也可以一键切换到顶视图、前视图或侧视图。
>
> 运动尾迹以颜色映射摆球的速度——从静止时的蓝色过渡到高速运动时的红色——让混沌运动的节奏变化一目了然。

#### 2.4 能量监控（1:30–1:45）

**【操作】**
1. 视线移到底部能量曲线面板
2. 指出三条曲线：动能（Ek）波动、势能（Ep）波动、总机械能（Etot）近乎水平
3. 将鼠标悬停到能量面板的数值显示上
4. 指出能量漂移百分比数字（应远小于 0.5%）

**【旁白文案】**

> 底部的能量监控面板实时追踪动能、势能和总机械能。在使用 RKF45 自适应积分器、容差百万分之一的条件下，一千秒仿真的能量漂移控制在千分之五以内——这是一个关键的教学指标，证明仿真不只是"看起来对"，而是物理上精确的。

### 场景 3：混沌现象高光（1:45–3:15）

**画面设计**：这是视频的核心亮点段落。展示蝴蝶效应对比器和声音化引擎两个差异化功能。

#### 3.1 蝴蝶效应对比器（1:45–2:30）

**【操作】**
1. 在探索模式的参数面板中找到"蝴蝶效应"按钮并点击
2. 屏幕从单视口变为左右双视口：金色摆 A vs 紫色摆 B
3. 确认初始差异显示为 `δθ₁ = 10⁻⁶°`
4. 点击"同步启动"（或等待自动开始）
5. **前 10 秒**：两个摆几乎完全重叠，画面看似静止
6. **10–20 秒**：两个摆开始出现肉眼可见的微小分离
7. **20–30 秒**：分离急剧扩大，两个摆走向完全不同的轨迹
8. 分离度超过 90° 时，界面出现脉冲提示
9. 镜头停留在分离最大的瞬间

**【旁白文案】**

> 让我们来观察混沌最标志性的特征——初值敏感性，也就是"蝴蝶效应"。
>
> 左侧的金色摆和右侧的紫色摆，初始条件仅相差百万分之一度——这个差异比一根头发丝的直径还要小七个数量级。两台独立的仿真引擎在各自的 Web Worker 中并行运行，除初始角度外，所有条件完全相同。
>
> 前几秒，两个摆的运动几乎无法区分。但随着时间推移，微小的初始差异被混沌系统指数放大——十秒后出现可察觉的分离，三十秒后，两个摆在空间中走向了完全不同的命运。这就是确定性系统的内在不可预测性。

#### 3.2 声音化引擎（2:30–3:00）

**【操作】**
1. 退出蝴蝶效应模式，返回单视口探索模式
2. 点击右上角声音化切换按钮（喇叭图标），开启声音化
3. 双摆运动的同时，音频引擎将角速度映射为音高和音色
4. 镜头在 3D 场景和声音化图标之间切换
5. 可以快速切换参数（如改变 `θ₁` 从 120° 到 45°），展示声音从"嘈杂混沌"变为"规则周期"的听觉对比
6. 关闭声音化

**【旁白文案】**

> 混沌不仅能被看见，还能被听见。我们自研的 Web Audio 声音化引擎，将两个摆的角速度分别映射为左右声道的音高和音色。当双摆做周期运动时，你听到的是规则的音阶；当进入混沌区域时，声音变得复杂多变——从听觉维度印证了混沌不是随机噪声，而是确定性系统中高度结构化的复杂性。
>
> 关闭声音化，我们继续。

#### 3.3 蝴蝶效应解读字幕叠加（3:00–3:15）

在后期制作中，在蝴蝶效应分离最大帧上叠加文字："初始差异 0.000001° → 30 秒后完全退相关"。此刻无需旁白，让画面说话。

### 场景 4：时间反演实验（3:15–4:15）

**画面设计**：这是展示"数值仿真中的物理哲学"的关键段落——用视觉证明混沌的时间不可逆性。

**【操作】**
1. 在探索模式中找到"时间反演"按钮并点击
2. 双摆先正向运行约 15 秒，积累运动历史帧
3. 点击"开始反演"——进入反演模式
4. 屏幕出现关键视觉元素：
   - 上方：轨迹叠加视图——虚线（正向轨迹）+ 实线（反向轨迹）
   - 下方：漂移曲线（Canvas 2D），以对数坐标显示反演偏差
   - 底部：三阶段叙事提示条（重合期→分离期→发散期）
5. 镜头先拍摄轨迹叠加视图（5 秒），再移向漂移曲线面板（10 秒）
6. 在漂移曲线面板上停留，展示指数增长趋势
7. 切换到精确反演模式作为对照：RingBuffer 直接回放，轨迹完美重合
8. 并排展示精确反演（完美重合）vs 数值反演（剧烈漂移）的对比

**【旁白文案】**

> 下一个实验揭示了混沌系统一个更深刻的性质——时间不可逆性。我们让双摆先正向运行一段时间，记录完整轨迹，然后命令仿真引擎以负时间步长重新积分同一个运动方程。如果世界是完全可逆的，它应该精确地沿原路返回。
>
> 但我们看到的是：反向轨迹逐渐偏离正向轨迹。这不是代码有 bug——这恰恰是混沌的数学本质。浮点运算中的微小舍入误差——大约在第十五个小数位——被混沌系统指数放大，使反向轨迹无法重走老路。
>
> 作为对照，精确反演直接回放历史帧，完美重合——这证明问题不在于我们的仿真引擎，而在于混沌系统本身：数学上是可逆的，数值上却是不可逆的。这个发现将"确定性不等于可预测性"这一混沌理论的核心命题，直观地呈现在学生面前。

### 场景 5：分析模式 — 定量化混沌（4:15–5:30）

**画面设计**：从"看混沌"到"算混沌"，展示三个定量分析工具——Lyapunov 热力图、分岔图、庞加莱截面。

#### 5.1 Lyapunov 指数谱热力图（4:15–4:45）

**【操作】**
1. 键盘按 `2`，切换到分析模式
2. 默认显示 Lyapunov 热力图（100×100 参数网格）
3. 鼠标悬停在热力图上不同区域：
   - 蓝色区域（λ < 0）→ tooltip 显示"规则运动"
   - 红色区域（λ > 0）→ tooltip 显示"混沌运动"
4. 点击热力图上一个红色网格 → 参数自动注入 → 键盘按 `1` 切回探索模式 → 3D 场景立刻展示对应混沌运动
5. 镜头跟随这个"从图谱到运动"的跳转过程

**【旁白文案】**

> 接下来我们进入分析模式，将混沌的感受转化为定量的测量。
>
> 屏幕上是一张一百乘一百网格的李雅普诺夫指数热力图。蓝色代表负指数，对应规则运动；红色代表正指数，对应混沌运动。李雅普诺夫指数的物理意义很直观——大于零意味着邻近轨道以指数速率分离，这正是蝴蝶效应的数学本质。
>
> 点击任意单元格，对应的参数组合会一键注入仿真引擎。学生可以从一张理论图谱跳转到三维直观运动——这种"算→看"的无缝衔接是本平台最核心的教学设计之一。

#### 5.2 分岔图（4:45–5:10）

**【操作】**
1. 切回分析模式，切换到"分岔图"标签页
2. 展示分岔图全貌：横轴为控制参数，纵轴为稳态 θ₂ 极大值
3. 指出清晰曲线段（周期运动区）和雾状散点带（混沌区）
4. 用鼠标框选一个感兴趣的区域进行放大
5. 竖直游标线联动当前仿真参数
6. 点击分岔图上的某个点 → 参数注入确认对话框弹出 → 注入后观察 3D 运动

**【旁白文案】**

> 分岔图是动力系统的"指纹"。我们将一个控制参数——这里是上摆的初始角度——在区间上扫描数百个点，对每个点提取稳态阶段的运动特征。
>
> 清晰的曲线对应周期运动——系统有规律地重复自己。雾状的散点带对应混沌运动——系统在每个循环中都产生不同的结果。框选放大可以观察分岔图的精细结构——自相似性、周期窗口——这些都是非线性动力学的标志性特征。

#### 5.3 庞加莱截面（5:10–5:30）

**【操作】**
1. 切换到"庞加莱截面"标签页
2. Worker 实时检测穿越事件，散点图动态生长
3. 展示老化效果：新点明亮→旧点逐渐透明消失（alpha 衰减）
4. 指出散点的分布模式：
   - 周期运动 → 有限个孤立点
   - 混沌运动 → 有结构的弥散分布（奇异吸引子的截面）

**【旁白文案】**

> 庞加莱截面是理解混沌几何结构的经典工具。每当上摆以正角速度穿过某个特定角度时，我们就在这个二维平面上记录下摆的位置和速度。
>
> 如果是周期运动，截面只会留下有限个点；如果是混沌运动，截面呈现出有结构的弥散分布——这就是奇异吸引子的截面。点随时间老化淡出，让学生能聚焦在最新的动力学结构上。

### 场景 6：实验模式 — 物理验证与创造（5:30–6:45）

**画面设计**：展示实验模式的三大功能——物理验证套件、受力拆解、Python 可编程沙箱。

#### 6.1 物理验证套件（5:30–6:00）

**【操作】**

   - 验证 2：单摆退化（m₂→0 时周期与理论值匹配）

**【旁白文案】**

> 一个仿真系统不能只有视觉效果——它必须经得起物理的检验。实验模式内置了三项自动化验证标准。
>
> 第一项，小角度线性化：当两个初始角都在五度以内时，系统的数值解应该与线性化解析解的偏差小于百分之二。第二项，单摆退化：当把下摆质量设为零时，上摆的周期应该严格等于单摆理论周期。第三项，能量守恒：无阻尼情况下，一千秒仿真的能量漂移应控制在千分之五以下。
>
> 三项全部通过，系统颁发绿色认证徽章——这不是装饰，是为仿真的物理可信度提供量化背书。

### 场景 7：故事模式 — 自动演示（6:45–7:45）

**画面设计**：展示故事模式的一键自动演示功能——这是最能打动评审专家的"演示效果"段落。

**【操作】**
1. 键盘按 `4`，切换到故事模式
2. 页面展示故事模式入口界面——胶片图标 + 文字说明
3. 点击"开始演示"按钮
4. 故事引擎自动依次执行 7 个阶段——此处需要录制约 60 秒的自动演示精华：
   - 阶段 1（5 秒）→ "一个摆，我们知道它会在哪里"——单摆稳定运动 + 相机特写
   - 阶段 2（5 秒）→ "再加一个摆，世界变得不可预测"——双摆混沌运动开始
   - 阶段 3（10 秒）→ "初始差异仅 0.001°，30 秒后它们形同陌路"——蝴蝶效应自动触发
   - 阶段 4（5 秒）→ "混沌不仅能看见，还能听见"——声音化引擎自动开启
   - 阶段 5（10 秒）→ "这不是随机，是有结构的复杂"——自动切换到分析模式
   - 阶段 6（10 秒）→ "甚至计算机也无法让混沌回头"——时间反演自动启动
   - 阶段 7（15 秒）→ "确定性系统的内在随机性——这就是混沌"——全景镜头拉远
5. 在阶段 5 或阶段 6 的任意时刻，点击画面任意位置"打断"演示
6. 导航栏解锁，恢复手动操作模式——展示"任意打断→自由探索"的设计

**【旁白文案】**

> 故事模式是一键自动演示功能——七阶段时间轴、电影式字幕、自动模式切换、相机自动运镜。总时长三分三十秒，全程无需人工干预。
>
> 每个阶段对应混沌教学的一个关键认知节点，从单摆稳定到双摆混沌，从蝴蝶效应到时间反演，最后以全景视角呈现"确定性系统的内在随机性"这一终极主题。
>
> 点击画面任意位置可以随时打断演示，导航栏解锁，学生可以立刻开始手动探索——从被动观看到主动操作，设计上实现了"演示→教学→探索"的无缝衔接。
