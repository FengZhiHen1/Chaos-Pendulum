## 一、开发目的

非线性动力学与混沌理论是 20 世纪物理学的三大革命性突破之一。然而在本科物理教学中，混沌内容长期缺位——多数《大学物理》课程以线性振动为核心，学生对"确定性系统产生不可预测行为"这一核心概念缺乏认知。实体双摆实验受限于机械加工精度、参数调节效率和数据采集可靠性，难以在 2 学时课堂内完成从现象感知到定量分析的完整教学流程。现有数字资源或为不可交互的演示动画，或为需安装配置的离线脚本，缺乏即开即用的教学工具。

本作品旨在提供一个**纯浏览器端、零安装门槛**的双摆非线性动力学虚拟仿真平台，以 RKF45 自适应积分引擎驱动高精度数值仿真，通过"感知→分析→验证→创造"四层递进认知架构，帮助学生从直观感受混沌现象出发，逐步建立定量分析能力，最终理解混沌的数学本质。

## 二、设计原理与方法

### 2.1 物理模型

系统仿真对象为平面理想双摆：两根无质量刚性杆 $L_1, L_2$，两质点 $m_1, m_2$，在均匀重力场中运动，含可选线性粘滞阻尼 $b$。以 $(\theta_1, \theta_2)$ 为广义坐标，通过拉格朗日方程导出角加速度显式表达式。支持单摆退化（$m_2 \to 0$）和小角度线性化两种经典极限情形的自动验证。

### 2.2 数值方法

自实现三种积分器，以策略模式组织：**RKF45**（Fehlberg 4(5) 嵌入对，自适应步长，容差 $10^{-7}$，默认方法）、**Velocity Verlet**（辛积分器变体）和**显式 Euler**（教学对照）。ODE 积分在 Web Worker 独立线程中执行，通过 Transferable Float64Array 零拷贝传输结果，RingBuffer（容量 6000 帧 = 100s）存储历史轨迹供时间反演与回放访问。

### 2.3 交互设计

系统包含四种工作模式，键盘 1–4 一键切换、仿真不中断。**参数分类响应**：连续参数（质量、摆长、重力加速度、阻尼）拖拽即时生效；初始条件参数（角度、角速度）拖拽时在 3D 场景中半透明预览，释放时才触发 Worker 重置。响应式布局适配桌面（三栏）、平板（底部抽屉）、手机（单栏聚焦）三类设备。

## 五、创新点

1. **四层递进认知架构**：将混沌教学从"现象演示"升级为"感知→分析→验证→创造"的完整闭环，每个认知层对应独立的交互模式，覆盖从入门到科研的全梯度需求。
2. **时间反演双模式实验**：精确反演（RingBuffer 回放）与数值反演（-dt 重新积分）并排对比，将"哈密顿可逆性 vs 浮点不可逆性"这一计算物理核心命题转化为直观可交互的教学实验。
3. **双 Worker 蝴蝶效应对比器**：两套独立的 Worker 实例以 δ=10⁻⁶° 初始差异并行积分，实时计算相空间分离度并触发脉冲提示，将 Lyapunov 指数的抽象数学定义转化为肉眼可见的视觉叙事。
4. **自研 RKF45 + Transferable 零拷贝管线**：从 ODE 右端函数到 Fehlberg 嵌入对算法、自适应步长控制、Worker 批量积分、Float64Array 零拷贝传输，全部自主实现，无第三方物理引擎依赖。
5. **物理验证 + 绿色徽章机制**：以可复现的量化标准自动检验仿真的物理正确性，通过后显示认证徽章——将"数值仿真可信度"这一元层次问题纳入教学体系。

## 六、应用与推广价值

**教学场景**：可直接嵌入《大学物理实验》《理论力学》《计算物理》课程——作为虚拟实验替代实体混沌摆、作为课堂演示工具展示非线性振动、作为编程对照案例讲解 ODE 数值解法、作为科普引入展示"从有序到混沌"的物理图景。

**推广可行性**：纯客户端架构（零后端、零网络依赖），产出物为自包含 HTML5 文件夹，支持 `file://` 协议离线运行。可嵌入课程网站、拷入 U 盘、部署在教室一体机或科技馆触摸屏。支持 Chrome/Firefox/Edge/Safari 主流浏览器，响应式布局覆盖桌面、平板、手机三端。

**科研延伸**：数据导出（CSV/JSON/PNG）支持导入 Origin、MATLAB 进行后续分析；Python 可编程沙箱支持修改运动方程、研究拓展模型；预计算管线（Python 离线生成 + IndexedDB 缓存）可作为"科学计算 + 前端可视化"技术路线的示范案例。

## 七、结论与总结

本作品以双摆为研究对象，构建了一个集高精度数值仿真、丰富可视化手段、完整教学闭环于一体的非线性动力学虚拟仿真实验平台。作品在物理原理上严格遵循拉格朗日力学体系，在数值方法上自实现 RKF45 自适应积分引擎，在交互设计上提供四层递进认知架构，在教学价值上覆盖从本科课堂到科研训练的完整需求。作品全部代码自主编写核心算法，纯客户端架构确保零门槛部署，具备大规模推广的技术条件。
